# Chrome 账号书签显示为空
Status: done
Category: bug

## 原因

宿主仅读取 `Bookmarks`，本机关联 profile 只有 `AccountBookmarks`。真实读取检查：现有索引 0 条，账号文件可解析 19 条。

## 验收

- 合并本地与账号书签，来源间 ID 不冲突，搜索与打开均对应正确条目。
- 检测两份文件的新增、修改、删除，损坏时保留上次可用数据并报告原因。
- 发现 profile 时识别账号书签；不修改 Chrome 文件。
- 宿主入口回归测试与本机只读检查通过。

## 完成

合并两份书签文件；本地 ID 保持兼容，账号 ID 加 `account:` 前缀。联合文件指纹检测变化，错误说明包含来源文件并保留上次可用索引。profile 发现识别仅有账号文件的目录。
26 项宿主测试与 7 项平台夹具通过；本机只读索引得到 19 条账号书签。详见 [验证记录](../verification.md)。
