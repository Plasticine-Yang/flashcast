# Flashcast 全产品重设计：第 02 轮方向探索

Date: 2026-10-05
阶段：方向待选；尚未替换正式产品 UI。

## 用户任务与范围

键盘优先的桌面启动器。用户唤起后找软件，或通过功能插件找到备忘录、剪贴板历史与 Chrome 书签，确认内容后执行默认操作。主要动作是选择结果并回车执行。

本次请求覆盖整个产品：搜索窗口、各种内容预览、快捷键、外观主题、功能插件、备忘录管理、剪贴板管理、Chrome 书签、配置工作区、同步与变更、运行环境与能力。先选择共同视觉方向，再延展并连接现有宿主入口。不会将小样里有限的页面误认为已完成全产品。

约束：正式窗口 640×420，最小宽度 480；保留 IME、方向键、回车、Escape 与 Ctrl+, 习惯。沿用语义主题 token 与声明式主题插件。尊重既有高频操作无动画的约定，不引入出场、输入、按键延迟。设置的持久化与错误反馈继续走现有宿主。

## 当前画面的问题

- 软件与命令的右栏重复图标、名称和默认操作，却占用超过一半横向空间。
- 搜索入口与选中态的蓝色边框同时争夺注意，首字符图标不能帮助识别对象。
- 搜索和设置没有共同的排版层级，设置控件像直接堆放的开发表单。
- 设置导航文字、正文与说明相近；关键状态缺乏视觉权重。

当前搜索与设置截图分别保存在 `baseline/search/page.png`、`baseline/settings/page.png`。

## 品类标杆与取舍

质量参考为 [Raycast Search Bar](https://manual.raycast.com/search-bar)、[Raycast Settings](https://manual.raycast.com/settings) 与 [Alfred Clipboard History](https://www.alfredapp.com/help/features/clipboard/)。参考用途是任务结构与质量基线，不照搬品牌、配色或无关功能。

Raycast 官方文档强调唤起后聚焦搜索、当前范围提示、键盘导航和可配置界面尺寸。保留熟悉的输入→结果→默认操作结构，删除重复预览，并将功能插件的查询范围作为可见入口。

Alfred 官方剪贴板文档提供搜索历史、文字/图片/文件与回车粘贴的工作方式。本轮从文档提取输入、历史列表、选中内容与操作反馈的任务关系，未据此宣称看过参考截图的视觉细节。对 Flashcast 的转译如下：

1. 顶部输入是主要入口，范围切换只占一行，内容完整进入首屏。
2. 结果是紧凑的连续列表，不拆成大卡片。
3. 当前选中有明确底色和操作提示，键盘指示不与正文争抢。
4. 预览用于确认正文或格式；软件不再固定显示重复详情。
5. 元信息降低视觉权重，但保留来源、时间、标签与格式。
6. 配置项按用户任务分组，表单反馈在当前操作附近显示。
7. 设置不用额外的主搜索行挤占纵向空间。
8. 采用中文产品字号与系统字体回退，不复刻 macOS 装饰。

Raycast 的图片代理未能加载，本轮未把其截图描述当作已验证视觉事实。

## 调性

高频、本地、私密的效率工具：安静、精致、中高密度、快速。强调色限制在选中与主要动作；不做背景插画或装饰摄影。最重要的素材是用户内容和真实应用图标。小样暂用统一语义线条图标，正式实现优先使用已有真实软件图标。

## 三个方向

| 方向 | 生成引擎与北极星 | 搜索结构 | 色彩身份 | 设置结构 |
| --- | --- | --- | --- | --- |
| 01 石墨 Graphite | 本地工作台的石墨表面；让结果占满窗口，用底部预览确认内容 | 通栏列表；仅内容结果展开底部预览 | 深石墨 + 冷银紫，选中行左侧短指示线 | 独立页头 + 深侧栏 + 当前设置 |
| 02 晨光 Ivory | 上午的自然光与轻薄桌面工具；用排版形成清楚秩序 | 单行结果为主，副标题按必要性收起；下方内容确认 | 亮白 + 墨紫，窄边选区与胶囊范围 | 浅侧栏、舒展标题、主题缩略图 |
| 03 航道 Rail | 高频入口的轨道；按任务切换内容面积 | 左轨道；软件通栏，备忘录/剪贴板结果与正文分栏 | 深绿入口轨道 + 亮白画布 + 淡绿选区 | 顶部分类导航，纵向空间交给正文 |

统一字体来自平台系统无衬线。输入 18–21px，结果正文 14px，设置标题 22–23px，辅助 12–13px。三个方向保持同一任务、内容与窗口尺寸。石墨的辨识来自选区节奏；晨光来自单行清单与紫色边界；航道来自入口轨道与动态内容分区。不是仅按明暗换皮。

**推荐 01 石墨**：最直接修复固定预览浪费空间的问题，搜索和设置共享深色表面语法，迁移现有布局代价较低。若倾向浅色，选 02；若想强化功能插件入口与内容浏览，选 03。

当前没有选定方向。用户选择与具体偏好收到后写入本文件，再深化正式产品。

## 小样能力与未完成部分

- `style-explorer.html` 可离线比较，含当前版与三个候选。单张查看可操作候选，不需要运行 React 项目。
- 每个候选包含搜索、范围切换、条件内容预览及快捷键、外观、备忘录、剪贴板、工作区代表页面。
- 搜索过滤、选择、外观选项、暂停记录和备忘录正文修改仅在小样会话内运行。它们没有接入实际配置工作区、剪贴板或软件启动。
- 标题修改、新建完整流程、会议邀请编辑、快捷键录制、主题安装、目录选择、克隆与同步仍是待深化部分；未连接的外部动作禁用。小样回车仅提示当前选择，没有伪造打开/粘贴成功。
- 功能插件、Chrome 书签、同步、变更、运行环境仅在全产品范围里规划，本轮没有制作其完整页面。
- 不使用生成图片：当前问题来自结构和层级，正文与对象图标已经承担主信息。
- 沿用高频操作无动画，本轮不宣称完成动效验证。

## 减法

删除软件结果的重复右栏详情、页框强蓝焦点装饰、设置页额外搜索行、冗长技术维护说明。晨光进一步收起软件副标题。设置标题改为具体的“快捷键”，不使用“随时唤起”等口号。正式实现会保留必要的对象名称、错误原因、当前状态、路径与操作结果。

## 验证与证据

- 三个方向在 640×420 的搜索、快捷键、外观、备忘录状态截图检查通过：无控制台错误、横向溢出与图片加载失败。
- 480×420 检查主题与备忘录的中文换行；修复“编辑”按钮被挤成两行。
- 石墨关键区使用 200% 截图检查。
- 浏览器交互检查范围切换、方向键、内容预览与备忘录正文修改；正文保存后读取列表得到相同文字（`shots/memo-edit/saved.jpg`）。截图工具的步骤操作未有效改变小样状态，预览改用可直达的 `memo-search` / `clip-search` 地址状态取证；只代表小样交互，不代表真实宿主功能。
- `pnpm exec tsc --noEmit` 通过。项目无 lint 脚本；未运行生产构建、全量测试或添加 UI 单元测试。
- 当前版本基线与比较页外壳有 `favicon.ico` 404，与画面无关，未修改项目配置。

证据在 `shots/`：三个方向的默认与设置状态、`*-narrow/` 窄窗口、`zoom/` 200%、`memo-preview/`、`clipboard-preview/`、`memo-edit/`。每个目录都有截图工具的 `report.json`。

**评审：没有独立评审，未打分。** 按 oil-ui 的方向探索协议先交给用户选择。选定后可在稳定初版做一轮隔离视觉评审；探索小样逐一评审约需每个 5–10 分钟，主要帮助检查层级、密度与可读性，未默认启动。

## 选定之后的实施顺序

1. 搜索入口、结果、默认/选中/空/错误状态，以及软件、备忘录、剪贴板文字/图片/文件、书签预览。
2. 设置外壳、快捷键、内置浅/深/跟随系统与主题插件兼容。
3. 备忘录、剪贴板、功能插件与 Chrome 书签管理。
4. 工作区关联与克隆、同步与冲突、变更与提交、运行环境能力。
5. 浏览器走查保存重读、失败保留输入、主题切换与窗口缩放；独立视觉评审后修正，更新 ticket 并提交。
