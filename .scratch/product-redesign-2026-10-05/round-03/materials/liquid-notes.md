# 石墨 · 液态玻璃配色研究

保留石墨方案的 640 × 420 通栏布局、文字层级、真实内容和操作入口。该轮研究只改变配色与表面材质。

| 配色 | 深色 | 浅色 | Flashcast 的含义 |
| --- | --- | --- | --- |
| Volt / 伏特 | 微绿石墨、硫黄闪电 | 暖灰纸白、硫黄金操作色 | 电荷释放的一道短促亮光；品牌辨识最强 |
| Arc / 电弧 | 冷石墨、冰蓝电弧 | 冰白、清晰电蓝 | 精确、快速的电弧；冷静的效率工具 |
| Silver / 银闪 | 黑银、极少香槟 | 白银、石墨字色、淡香槟 | 金属边缘的瞬间反光；最克制的一套 |

语义配色变量与毛玻璃版本逐项一致，保证直接切换材质时仅比较表面差异。

## 材质约束

- 外窗以薄透明表面、凸边高光、局部边缘模糊和光学色带体现液态感；实画精修后将凸边缩至 3.5px，浅色边缘光带降至 28% 强度，保留独立的 1px 顶部高光，减少实体白框感。
- 范围控件只有当前范围承担小型镜片表达，其他范围保持安静。
- 列表保持平整阅读层，不给每行套玻璃气泡，不让文字受滤镜影响。
- 深色窗口在明亮或文字密集桌面上提高局部阅读衬底：正文不透明度 60%，搜索、范围和底栏为 64%；外圈仍维持薄透明玻璃。使用局部填充保障辅助文字，不增加模糊。
- 浅色实画在暗色桌面上需要更稳的亮度：浅色统一正文阅读衬底 72%，搜索、范围和底栏 68%；浅色搭配暗色桌面时，将外壳填充提高至原背景色的 76%。这是保证辅助文字和搜索占位文字清晰的取舍，保留薄边和高光，普通中性及彩色桌面仍维持原有 49–50% 透明外壳，不改品牌原色。
- 列表、范围切换与设置导航没有过渡动画，保持高频操作反馈直接。
- 全部六套都有独立的表面、前景、辅助文字、选中态及主操作前景颜色。浅色强调色主动降低明度，避免亮黄或冰蓝文字不可读。
- 与毛玻璃比较时共用同一桌面背景。液态用 10px 模糊保留更多背景形状；边缘用高光和局部 2px 滤镜提示厚度。毛玻璃应以较均匀、较强的模糊表现扩散。

## 参考及实现边界

[Apple 的 Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 强调将玻璃用于浮于内容上方的导航层，并避免玻璃叠玻璃；[Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 将材质用于不遮挡内容的控件与导航。这一小样将外窗视作唤起式工具的容器层，在内部恢复稳定的阅读层。

这是浏览器 CSS 对光学表面的近似研究。没有调用 Apple 原生材质、动态环境采样或真实几何折射。凸边色带和局部滤镜只提供边缘折射的视觉暗示，不等于真实背景位移。无需 SVG defs，避免高复杂度滤镜和浏览器差异影响中文阅读。

## 集成

加载顺序：石墨原有 CSS → 共享配色/背景 CSS → `materials/liquid.css`。

```html
<body data-material="liquid" data-palette="volt" data-appearance="dark">
```

材质、配色及深浅模式全部由上述 body 属性决定。所有规则都有 `body[data-material='liquid']` 前缀，不污染毛玻璃版本。语义变量作用于 `.window`，覆盖石墨文件中局部变量。未改窗口尺寸或布局。

本子任务尚未进行截图、浏览器验证或独立评分；主任务集成后统一验证所有六种组合及关键页面。
