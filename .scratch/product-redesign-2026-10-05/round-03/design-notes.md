# Flashcast：石墨配色与玻璃材质，第 03 轮

日期：2026-10-05。交付为可操作设计小样和比较页，尚未接入正式产品。

## 已确定的方向

用户选定第 02 轮的石墨布局，要求简洁、精致，体现 Flash 闪电感；每套配色有深浅模式，同时比较毛玻璃和苹果液态玻璃式效果。

保留 640×420 主窗口、通栏结果、按内容出现的底部预览和设置侧栏，最小宽度 480。输入与结果仍是主体，强调色只落在闪电标记、选中位置和主要动作。不新增装饰插画或全屏霓虹。

## 配色

| 配色 | 深色基底 / 强调 | 浅色表达 / 强调 | 推荐理由 |
| --- | --- | --- | --- |
| 雷光 Volt | 微绿石墨 / `#e1ec9c` | 暖灰白 / `#79610b` 深金 | 最贴近 Flashcast，像短促的硫黄闪光；优先推荐 |
| 电弧 Arc | 冷石墨 / `#a2c4ff` | 冰白 / `#265b9d` 电蓝 | 更冷静、清晰，适合长时间使用 |
| 银闪 Silver | 中性炭灰 / `#ddc8a6` 香槟 | 陶瓷白 / `#756044` 深香槟 | 最克制，闪电表现为小面积金属反光 |

三种配色 × 深浅模式 × 两种材质，共 12 种效果。两种材质使用相同的语义配色，切换时不改变布局和当前内容；浅色强调色单独降低明度，避免把亮黄或浅蓝直接用于浅底文字。

## 材质与取舍

毛玻璃使用一个均匀的模糊平面，26px 模糊、115% 饱和度和稳定底色。桌面颜色轻微渗入，列表和设置更安静；明亮或文字桌面提高遮蔽，优先保证阅读。推荐 **雷光 + 毛玻璃** 作为正式设计的起点。

液态玻璃使用 10px 模糊保留背景形状，薄凸边、顶部高光与边缘光带表达厚度。列表保持平整，不给每个结果套玻璃气泡。实画检查后将亮边从 7px 缩到 3.5px，降低浅色边缘强度；为浅色正文和深色明亮桌面增加局部阅读衬底。它更有光学质感，也更受桌面明暗影响。

“减少透明度”切成同配色实底；不支持 backdrop-filter 时提供实底回退。当前场景遮蔽规则通过对比页的背景类型触发，尚未实现真实桌面亮度的自动检测。

参考 [Raycast Themes](https://manual.raycast.com/themes) 的深浅主题组织，以及 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 对材质层级与稳定阅读面的说明。没有宣称精准复刻参考产品截图。

这是浏览器 CSS 的材质近似：没有使用 Apple 原生 Liquid Glass、真实背景折射位移或操作系统桌面采样。真实宿主窗口的透明、模糊、性能和跨平台差异留到选定后的接入阶段验证。

## 如何比较

打开 `style-explorer.html`，01–03 是毛玻璃，04–06 是液态玻璃，另有原石墨不透明基线。进入“单张查看”后可切换深浅、材质和五种桌面背景，比较时保持颜色与背景一致；检查文字细节使用“实际尺寸 100%”。

每个源小样也可独立打开，如 `volt-frosted.html`。查询参数 `state=dark-home` / `light-home` / `dark-memos` / `light-memos` 指定深浅和代表页面；`scene=neutral|bright|dark|color|desk` 指定背景。`assemble.py` 从上一轮石墨源生成六个配色材质候选和 manifest，比较页由 oil-ui 官方生成器组装。

桌面背景是 CSS 编写的材质测试场景，文字桌面内容是本轮设计的虚构文件列表，不是用户工作区内容。候选继承上一轮小样的有限交互；没有连接真实软件启动、剪贴板、工作区或持久化配置，完整功能边界见上一轮说明。

- 六个候选均检查深浅搜索与备忘录设置，共 24 个状态；截图工具报告无控制台错误、横向溢出或图片加载失败，并查看了实际画面。

- `pnpm exec tsc --noEmit` 通过；仓库没有 lint 脚本。未添加 UI 单元测试、未运行生产构建或全量测试。
- 沿用高频操作立即反馈，没有新增动效，因此没有动效验收结论。

证据位于 `shots/`：六个候选目录保存四种状态及 `report.json`；`bright-desktop/`、`dark-desktop/`、`color-desktop/`、`text-desktop/` 是背景检查；`narrow-frosted/`、`narrow-liquid/` 是窄窗口；`zoom-liquid/` 是 2 倍像素；`pair-frosted/`、`pair-liquid/` 是雷光深浅成对截图；`liquid-settings-light.jpg`、`liquid-settings-dark.jpg` 是实际浏览器设置画面。

本轮为配色与材质探索，完成视觉自检，**没有独立评审，没有评分**。毛玻璃与液态材质由两个设计子任务并行制作，不能把制作协作当成隔离评审。
