# Flashcast UI/交互重设计 — 方向探索（第 01 轮）

## 产品与任务

- **品类**：键盘优先的桌面启动器（launcher / command bar）。同类最鲜明的是 Raycast、Linear 的 Cmd-K、Spotlight、PowerToys Run。
- **用户来首屏做什么**：唤起窗口，输入几个字，用 ↑↓ 认准一条，回车打开软件 / 粘贴备忘录或剪贴板 / 在 Chrome 打开书签；主要动作发生在**选中那一刻**。
- **基准结构（沿用）**：顶部一个输入、下方结果列表、键盘选择、回车执行、Esc 关闭、底部操作提示。这是用户已经学会的，不重学。
- **要打破的套路**：默认的「深色浮窗 + 放大镜 + 应用图标圆角块 + 纯蓝整块选区」，以及「所有来源混在一个平列表里」。
- **本轮交付**：4 个方向的首屏小样，并排比较后由你选定，再在真实项目里实现（含设置页）。

## 现状（基线）

现有界面：浅色中性底、蓝色整块选区、首字符占位图标、14px 单层灰、无层次、无动效。问题不在配色单一，而在**没有主角、没有质感、选中态太廉价**、本地内容（备忘录正文/剪贴板图片）没有存在感。

## 调性基线（四个方向共守）

这是一个每天唤起几十次、靠肌肉记忆的工具：**安静、精致、密、动作快**。四个方向都在这个调性内，靠色彩身份、构图、字体与主视觉拉开差异，不放进任何「安静极简保底方案」。

| 刻度 | 取值 | 依据 |
| --- | --- | --- |
| 能量 | 安静 | 高频使用，强刺激会累 |
| 完成度 | 精致 | 桌面工具的门面 |
| 密度 | 密 | 一屏尽量多结果 |
| 分量 | 中 | 页头轻，选中重 |
| 严肃度 | 偏庄重 | 效率工具，动效幅度小 |

## 方向卡

### 01 夜航 Night Watch

- **北极星**：像深夜值班室里随手擦亮的一块磨砂玻璃，安静，但被选中的那一行有温度。
- **生成引擎**：材质 × 环境 —「深夜工作室的一块磨砂玻璃 × 桌角的炉火」。来自本机常驻、私密、多在夜间唤起。
- **标杆与取舍**：拆 Raycast。留：深色玻璃浮窗、顶部输入、底部键帽栏、柔和选中。换：把 Raycast 的紫红换成**暖炉火橙**；选中用左侧一条会滑动的暖色指示条 + 极浅底色，而不是整块填充。
- **首屏骨架**：内容页 — 首屏就是第一排结果。竖排：搜索行（48px）/ 结果列表（填满）/ 选中项预览条（仅备忘录、剪贴板、书签）/ 底部键帽栏（36px）。
- **字体**：无衬线（OPPO Sans / Noto Sans CJK）。标题 14.5/500，副标题 12/400 muted，等宽数字。
- **色彩**：底 `#0b0c0f`，玻璃 `#1b1d23`，文字 `#e9eaef` / `#9398a4`，强调 **`#f2a76b` 炉火橙**，选中底 `rgba(242,167,107,.10)`，边框 `rgba(255,255,255,.08)`。
- **主视觉**：顶部一条 1px 暖色渐隐高光；真实应用图标（圆角 9）。
- **图标**：不用图标库；除真实应用图标外用 1.4px 内联符号。
- **控件语法**：圆角 16（窗）/ 10（行）/ 8（控件）；1px 细边；按下缩到 0.98。
- **动效**：咔嗒 — 选中指示条「滑入」（抽屉阻尼 ~280ms）；预览条「流淌」展开；首次进入窗口如拉帘亮起，结果按 40ms 依次淡入。
- **记忆点**：暖色指示条从上一行滑到下一行，行内容轻微抬起；唤起时整窗渐亮。
- **结构性突破**：设置做成右侧滑出的独立层，窗口本身不换页，强化「随时收回的浮窗」。
- **放弃**：纯蓝选区、首字占位图标、整块选中填充。

### 02 纸页 Paper Index

- **北极星**：像翻一本属于自己的索引册，安静、可读、有书卷气。
- **生成引擎**：其他领域表现形式 —「图书馆的卡片目录 / 私人笔记本」，来自配置工作区是本地 Git 仓库、备忘录是带标签的 Markdown。
- **标杆与取舍**：基准取笔记/阅读类（Bear、Things 的排版克制）。留：列表优先、键盘操作。换：**按来源分节并编号**（命令 / 软件 / 备忘录 / 剪贴板 / 书签），用细横线与分节标题组织，而不是一堆圆角卡片。
- **首屏骨架**：内容页 — 通栏下划线式搜索行 / 分节结果列表 / 下方一张「卡片」预览 / 细线键帽栏。
- **字体**：标题用**衬线**（Noto Serif CJK），正文无衬线，标签与数字等宽小号。
- **色彩**：纸底 `#f6f1e7`，面 `#fffdf8`，墨 `#24211b` / 次 `#6f6a5e`，强调 **`#b4472f` 赭红**，点缀墨绿 `#3f6b52`。
- **主视觉**：排版本身 + 分节编号（01 / 02）。
- **图标**：几乎不用；用字符与编号（§、→、※）。
- **控件语法**：小圆角（4–6）；1px 墨线；焦点用加粗底线而非发光；按下像盖章一样下压。
- **动效**：盖章下压（执行）；分节标题吸附顶部；首次进入逐行「书写」出现。
- **记忆点**：选中行左侧出现一个折角书签符号；预览是一张带横线的索引卡。
- **结构性突破**：结果按来源分组编号，打破「所有条目混在一个平列表」。
- **放弃**：玻璃模糊、霓虹强调色、圆角卡片堆叠。

### 03 信号 Signal

- **北极星**：像调准频率——输入时结果一台一台被「锁定」，回车把信号发出去。
- **生成引擎**：角色原型 —「一个冷静的信号台操作员」，来自产品名 Flashcast 与「输入即锁定目标」的行为。
- **标杆与取舍**：拆仪器/终端类（Warp、btop）。留：等宽、高密度、键盘优先。换：不做纯黑终端绿；用**深石板 + 荧光青绿 + 琥珀**双色；结果行带类型字形（命令 `>`、备忘录 `¶`、剪贴板 `⌘`、书签 `#`）而不是应用图标块；顶部加一条仪器状态栏。
- **首屏骨架**：内容页 — 顶部仪器状态栏（范围 / 条数 / 快捷键）+ 提示符式搜索行 + 等宽结果行 + 底部信号条。
- **字体**：等宽（Noto Sans Mono CJK）。13px 正文，11px 状态。
- **色彩**：底 `#0e1416`，面 `#131b1d`，文字 `#d6e4e2` / `#6f8a88`，主强调 **`#4fd1b5` 荧光青**，副强调 `#f0b45a`，选中底 `rgba(79,209,181,.12)`。
- **主视觉**：字符与符号本身；选中指示用 `▌` 与一条扫描线。
- **图标**：不用图标库；等宽字形与 Unicode 符号。
- **控件语法**：几乎无圆角（2–4）；1px 网格线；字符按钮 `[ 保存 ]`。
- **动效**：扫描线沿列表移动；结果行从右往左「雷达扫过」；首次进入字符逐格打印（打字机）。
- **记忆点**：输入时一条细扫描线掠过列表；回车时当前行像发报一样闪一下。
- **结构性突破**：顶部仪器状态栏，打破「输入框是唯一页头」。
- **放弃**：圆角卡片、模糊玻璃、应用图标。

### 04 棱镜 Prism

- **北极星**：不用回车才知道是什么——选中的那一刻，内容已经在旁边展开。
- **生成引擎**：有意打破常规 —「把结果与现场预览同时摆上台面」，来自 Flashcast 的核心动作：粘贴/打开之前必须先确认完整内容（备忘录正文、剪贴板图片、书签链接）。
- **标杆与取舍**：拆 Linear Cmd-K（紧凑、键盘、克制）。留：紧凑、键盘、清晰层级。换：结果列表压到左栏 38%，右栏是选中项的**常驻现场预览**，打破「选中后弹一条可折叠预览」的套路。
- **首屏骨架**：内容页 — 搜索行跨顶；下方左右分栏（结果 38% / 预览 62%）；底部键帽栏。
- **字体**：无衬线（OPPO Sans / Inter）；标题 14/600，预览正文 14/1.7，元数据等宽小号。
- **色彩**：底 `#ffffff`，面 `#f5f6f8`，墨 `#0d0f14` / 次 `#6a7280`，强调 **`#2b62ff` 钴蓝**，命中标记 **`#ffe45c` 荧光黄**（只用于搜索命中的字符）。
- **主视觉**：右栏预览本身（大图 / 大段文字）；左栏有荧光黄命中标记。
- **图标**：1.5px 细描边内联，少量。
- **控件语法**：圆角 8；1px 浅边；焦点 2px 蓝环；选中行左侧蓝条 + 极浅蓝底。
- **动效**：右栏预览内容淡换（同尺寸不缩放，避免重影）；命中黄标逐个出现；首次进入预览先到、列表随后排入。
- **记忆点**：搜索命中字符被荧光黄高亮，像马克笔划过；切换选中时右栏外框不动、内容淡换。
- **结构性突破**：预览从「下方展开条」变成「常驻右栏」，成为首屏主角。
- **放弃**：卡片网格、把预览藏起来。

## 差异检验

| | 首屏骨架 | 字体 | 色彩身份 | 主视觉 |
| --- | --- | --- | --- | --- |
| 01 夜航 | 列表 + 底部预览条 | 无衬线 | 深色玻璃 + 炉火橙 | 应用图标 + 暖指示条 |
| 02 纸页 | 分节编号列表 + 卡片预览 | 衬线标题 | 暖纸 + 赭红/墨绿 | 排版与编号 |
| 03 信号 | 仪器状态栏 + 等宽行 | 等宽 | 深石板 + 荧光青 | 字符/符号 + 扫描线 |
| 04 棱镜 | 左右分栏（结果 / 预览） | 无衬线 | 亮白 + 钴蓝/荧光黄 | 右栏现场预览 |

- 四项至多一项相同：01 与 02 色彩不同、字体不同、主视觉不同（骨架都是列表）。
- 不按明暗分方向：01 是暖玻璃、03 是冷荧光字符，身份不同；02 纸、04 白，色相家族不同。
- 至少一个极端：03 在密度与字符语言上取极端；02 在编辑性上取极端。
- 至少一个打破套路：02 打破平列表，03 打破唯一页头，04 打破预览折叠。
- 不撞脸：01 拆了 Raycast 但换掉主色与选区表达；04 拆 Linear 但改了结构。

## 推荐

- **最稳、最快落地**：01 夜航。桌面启动器的用户已经被 Raycast 教育过，夜航在他们熟悉的结构上把质感补齐，风险最低。
- **最像 Flashcast 自己**：04 棱镜。它把「本地内容预览」这个别家没有的优势变成首屏主角。
- 若你要一个立刻和现有「浅色默认」拉开距离、又不牺牲可用性的答案，选 01；若你愿意用一点结构改动换辨识度，选 04。

选定后我会在真实项目里实现该方向（搜索首屏 + 设置页 + 三处动效），并复用现有主题变量体系。

## 实现（选定 04 棱镜后）

- **搜索首屏**：`.search-body` 改为「结果 | 常驻现场预览」两栏。选中的是备忘录 / 剪贴板 / 书签时右栏给出完整正文或图片（`MemoPreview`）；软件与命令由新增的 `StageInfo` 在右栏给出条目信息，右栏不再空着。
- **命中高亮**：结果标题里第一次出现的查询串被包成 `<mark>`（荧光黄 + 深色前景，两种外观都可读）。纯文本节点，不存在注入面。
- **选中指示**：一行 `.result-band` 底板在结果行之间滑动（180ms 回弹），行本身保持 `transition: none`。
- **主题 token**：内置浅色换为棱镜配色（冷白 `#ffffff`、钴蓝 `#2b62ff`、`rgba(13,15,20,…)` 中性线），深色保持不变（`#202226` 表面被测试断言，且已是冷色）。`mockThemes.ts` 同步。荧光黄属于 UI 自有语义，不由主题提供。
- **未改动**：窗口尺寸保持 640×420；设置页结构（左目录 + 右内容区）与全部 `data-testid` 不变；响应式在窄屏下把预览退到列表下方。
- **验证**：`pnpm exec tsc --noEmit` 通过；`pnpm ui-check` 69/69 通过（含浅色 / 深色 / 跟随系统 / 安装主题下的对比度、状态可辨识与「高频操作无动画」断言）。本机未安装 cargo，主题可读性用与 `flashcast-core` 同口径的脚本核对，全部满足。
- **交互动效说明**：本项目明文约定高频操作（唤起、键盘选择、查询更新）无动画，并由 `ui-check` 断言；因此三处基本动效里只保留「选中底板滑动」这一处，出场与按下反馈按项目约定保持即时到位。

- **过程证据**：`shots/` 下每个方向一张 1280×900 全屏，另有 `shots/a-interact/`（↑↓ 移动选区 + 回车反馈）、`shots/d-typed/`（输入即过滤 + 荧光黄命中高亮）、`shots/a-night-watch-m/`（390 宽窄屏）。

- **范围**：探索阶段的对比页先交给你选定；随后在真实项目里实现了 04 棱镜（搜索首屏 + 设置页外观）。设置页结构未改，动效按项目「高频操作无动画」的约定收敛。
