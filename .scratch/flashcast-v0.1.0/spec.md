# Flashcast v0.1.0：跨平台启动器、Git 配置工作区与插件

Status: ready-for-agent
Category: enhancement

本文依据已确认的对话整理。用户于 2026-10-01 确认测试边界、18 张 ticket 的粒度及依赖关系，现正式发布到仓库的本地 tracker。首次交付包含已讨论功能及 GitHub Release，不把仅含软件启动的演示当作最终交付。

## Problem Statement

用户希望在 Linux、macOS 和 Windows 上通过一个简洁、键盘优先的入口打开软件、取回剪贴板历史、搜索 Chrome 书签，以及检索并粘贴常用备忘录。现有操作分散在不同应用中，配置与常用内容也难以通过一个用户可控制的 Git 仓库维护。

当前仓库只有协作规则和技能配置，没有应用实现、测试先例、版本或 Release。本地可以检查 Linux 环境；缺少本地 Windows 和 macOS 环境，因此需要尽早通过 GitHub Actions 验证对应平台的构建与可执行的系统行为，并如实记录桌面交互的覆盖范围。

## Solution

提供一个常驻桌面的 Flashcast 启动器。用户通过全局快捷键打开紧凑的搜索浮窗，输入软件名即可启动软件，输入插件关键词进入对应搜索范围，或直接输入备忘录标签获得可粘贴的内容。

关联本地 Git 配置工作区，或从远端克隆工作区；工作区维护设置、插件清单与版本、主题和备忘录。剪贴板历史、缓存、凭证以及设备特定信息保留在本机。提供配置变更查看、提交和远端同步。

随应用提供剪贴板、Chrome 书签和备忘录三个功能插件，以及默认主题插件。功能插件共享搜索、列表、预览与操作栏。默认采用紧凑列表，需要阅读长内容或查看图片时展开内容预览。开发过程中持续运行三平台 CI，完成后发布带安装包、校验值和中文发布说明的 v0.1.0 GitHub Release。

## Implementation Decisions

- 首版以 Tauri 2、Rust 和 React/TypeScript 为实施基线；通过最早的可运行切片验证其适用性。出现不能满足核心要求的框架限制时记录证据并重新评估，不以框架宣称代替验证。
- 采用宿主、功能插件、主题插件和平台适配层的划分。宿主管理窗口、查询范围、结果排序、预览、操作执行及配置工作区；平台适配层封装软件发现、启动、快捷键、剪贴板及粘贴。测试优先从宿主命令或用户操作入口穿透这些边界。
- 首屏搜索软件和备忘录。插件关键词完整匹配后可进入对应范围；识别中文与英文别名。关键词与标签冲突时保留明确的插件入口和带来源的备忘录候选，避免静默覆盖标签命中。
- 首屏空查询显示有限数量的快速访问项，查询结果采用稳定排序，区分软件、命令和备忘录；标签精确匹配优先于较弱的内容匹配。不在首屏默认检索全部剪贴板历史或书签。
- UI 延续已选择的紧凑列表：桌面窗口基准宽约 640px，约 14px 圆角，中性背景、细边框、轻阴影，搜索输入约 16px、正文约 14px、辅助信息约 12px。窗口尺寸保持稳定，预览按需展开，低分辨率与系统缩放下仍可操作。
- 唤起、关闭、键盘选择、查询更新、进入插件与回车执行无动画；低频鼠标菜单可以使用约 150–180ms 的轻微透明度和缩放过渡。尊重减少动态效果设置。选中、焦点和错误状态可辨识，主题切换不改变关键操作位置。
- 操作栏根据当前结果明确显示打开、在 Chrome 打开或粘贴。Escape 优先关闭菜单，其次返回上一查询范围，最后关闭窗口。返回时恢复此前的查询、选择和滚动位置。组合输入期间的回车不执行命令；异步查询以当前查询为准，鼠标移动不改变键盘选择。
- 功能插件声明标识、版本、关键词别名、首屏搜索贡献和所需能力；返回统一结果、预览与默认操作。三个随应用提供的官方插件使用同一契约。停用插件同时停止搜索贡献和后台活动。
- 原生能力只能经宿主授权接口调用，权限校验放在原生边界；有可执行任务的插件运行于隔离任务边界，并具有取消、超时和错误处理。同步异常、超时与后台监听错误必须保持宿主可用。首版不建立对任意第三方代码安全运行的承诺。
- 主题为声明式插件包，支持安装本地主题、启停与切换。默认提供浅色、深色和跟随系统；颜色、字体、间距、圆角、阴影和选中状态使用统一语义，功能插件采用宿主组件。无效主题保留上次可用外观。
- Git 配置工作区保存可读设置、插件清单及版本、主题配置和带标签的 Markdown 备忘录。用户可选择本地仓库、初始化新仓库或从远端克隆。切换前校验目标工作区，不覆盖已有用户文件。
- 配置与备忘录的写入具有完整性保障；外部修改只在验证成功后生效，失败保留最后有效状态。应用写入与外部文件监听不会相互形成写入循环。
- SQLite 用于本机历史与索引，较大内容存储为本机附件；索引可以重建，不作为配置的唯一来源。Chrome 可执行路径、profile 路径、应用索引、权限状态、日志和凭证保留在本机，工作区可以记录可迁移的偏好。
- Git 变更查看和提交只能作用于选定配置工作区；差异和提交目标透明呈现，不把无关修改默认纳入提交。网络操作复用用户可用的凭证管理，凭证不写入工作区或日志。
- Git 同步优先处理无冲突的快进拉取与推送。脏工作区、分叉、冲突、鉴权失败和离线都有明确状态；保留内容，提供外部处理与重新检测入口，不强推、不自动丢弃更改。首版不要求内置三方合并编辑器。
- 备忘录包含稳定标识、标题、多个标签和文字正文；通过插件进行创建、编辑、删除与预览，变更保存到工作区并可提交。标签作为首屏索引入口，相同标签可命中多条内容。
- 粘贴是宿主级操作：保存唤起前的目标应用，准备所需剪贴板格式，关闭浮窗，恢复目标应用并发起系统粘贴。权限缺失、目标失效或桌面不支持时复制内容并明确提示手动粘贴。不能把焦点转移给其他应用后继续注入。
- 剪贴板在用户启用后后台监听，按一次复制事件保存受支持格式集合、时间、摘要、附件及来源信息（平台可提供时）。文字、图片、HTML/RTF、文件列表分别验证；保留与恢复按平台公开的可序列化格式实现，不承诺任意应用私有格式。
- 视频第一版按视频文件处理，不包含录屏或从任意应用提取视频片段。文件引用标明原文件依赖；用户可明确保存受容量限制的本机副本。图片及已保存文件副本在原来源消失后仍可恢复，历史删除与过期清理同步回收不再引用的附件。
- 剪贴板支持文字搜索、图片缩略图、文件名称与类型、置顶、删除、清空、去重、自身写入循环抑制、暂停、保留期限与容量限制。无可索引文字的媒体通过名称与元数据查找，不承诺 OCR 或视频内容搜索。
- Chrome 书签第一版读取用户选择的本地 profile，保存可重建索引，按标题、网址和目录搜索；检测变化后刷新。在选定 Chrome profile 打开时正确处理参数与链接，不经拼接 shell 命令执行。首版不依赖配套浏览器扩展。
- 尽早引入 GitHub Actions。开发 CI 覆盖 Linux x64、Windows x64、macOS Apple Silicon 和 Intel 的必要构建；分别提供可执行的平台检查与证据，环境不支持的检查记为未覆盖，不作为通过。Linux 本地明确记录实际 X11/Wayland 环境，不能用 X11 检查推断 Wayland 支持。
- 开发阶段提供候选安装包，正式发布包括 Linux x64 的 AppImage 和 deb、Windows x64 的 exe 安装程序、macOS Apple Silicon 与 Intel 的 dmg。候选包只是构建产物，不提前发布正式版本。
- macOS 至少按适用方式配置 ad-hoc 签名；有用户提供的凭证时接入正式签名与公证。Windows 有凭证时签名。无凭证时如实提供签名状态和安装说明，不宣称已签名或已公证。
- 首次正式版本为 v0.1.0。版本元数据、Git tag、构建提交与资产命名一致；发布流水线汇总所有必需结果后上传对应提交的产物、生成 SHA256 校验值和中文说明，再正式发布。失败重试可追溯，不能混入其他提交的旧产物。
- 实现 ticket 与适用验证完成后流转为 done，并与实现一起以中文提交说明创建 Git commit。规划发布确认后也创建中文 commit。GitHub Release 发布已获得用户授权，完成开发和检查后按流程执行，无需再次引入确认门槛。

## Testing Decisions

- 已确认的主测试边界为宿主对外的查询与命令入口：从查询、选择、编辑、关联、同步或执行操作开始，验证用户看得到的结果、工作区内容和本机持久化结果。尽量穿透真实索引与存储，避免按每一层分别测试同一个实现细节。
- 仅在系统与外部环境的适配边界提供可控制替身；纯核心行为用确定性平台环境，系统集成检查调用真实平台接口。替身检查和真实系统检查在报告中分开，替身通过不证明平台适配通过。
- 非 UI 集成测试覆盖查询范围、关键词与标签冲突、异步过期结果取消、备忘录持久化、配置重载错误、插件停用与失败隔离、历史去重与附件清理，以及宿主原生操作权限。
- Git 行为使用临时工作区和本地 bare 远端验证实际变更、提交、克隆、快进拉取、推送、分叉和未提交修改保护。只有鉴权与网络失败才在相应外部边界控制，不依赖个人凭证运行常规测试。
- Chrome 行为使用临时 profile 和书签样本验证搜索与刷新，通过宿主执行入口确认发送给 Chrome 的网址和 profile 参数；在 Chrome 可运行的目标环境补充实际打开检查，不把参数检查等同于浏览器运行成功。
- 每个平台分别检查软件发现与启动、剪贴板文字/图片/富文本/文件恢复，以及可运行的快捷键和粘贴流程。需要交互桌面或系统权限的检查先检测条件，无法执行时输出原因与证据；必需的构建和核心行为失败仍阻断发布。
- UI 不添加单元测试。通过手动和浏览器交互检查紧凑/预览布局、键盘导航、中文输入、查询返回、主题与系统缩放、错误反馈和设置；可执行的桌面交互检查保存日志与截图。真正的目标应用粘贴需要检查目标内容，不能只以“已发送粘贴命令”为成功。
- 平台能力报告区分实测通过、实测失败与未覆盖，并记录系统版本、架构、Linux 会话类型、签名状态与必要权限；安装包构建成功单独列示。
- Release 验证检查全部目标资产、安装包版本、SHA256 校验值、对应 tag 和提交，以及中文说明。每个必需平台任务成功后才允许发布；可选桌面检查未覆盖时在说明中明确列出限制。
- 仓库目前没有可复用的实现与测试先例；本次从上述最高层边界建立最小测试基础，不建设与首版无关的测试框架或 UI 快照体系。

## Out of Scope

- 自动更新、插件市场、任意第三方可执行插件的公共开发 SDK，以及对未审计第三方代码的安全运行保证。
- 手机端、其他浏览器、云端账户同步服务、剪贴板跨设备同步。
- OCR、视频内容检索、录屏、任意应用私有格式的完整复制恢复，以及不限大小地保存所有文件。
- Chrome 书签编辑、网页内容索引与配套 Chrome 扩展；第一版提供本地书签搜索和打开。
- 富文本笔记编辑器、提醒和任务管理；备忘录第一版为带标签的文字内容。
- 内置三方 Git 合并编辑器、自动强推或丢弃更改，以及代用户申请和购买签名证书。
- 首版目标之外的 Linux/Windows ARM 安装包和全部 Linux 发行版、桌面及系统版本的兼容性承诺。
- 把 macOS/Windows 构建通过或模拟系统测试通过写成真实桌面全流程已验证。

## Further Notes

- 已讨论的两个 UI 布局是紧凑列表与内容预览；默认采用紧凑列表，内容预览按需展开，主题示意不是成品系统行为验证。
- 术语统一使用配置工作区、宿主、功能插件、主题插件、备忘录、剪贴板历史、平台适配层。剪切板只作为输入别名，不另建插件。
- 文件副本、视频语义、任意私有格式及缺少交互环境的能力限制已明确列出并获得用户确认；不把技术限制藏到实现结束后。
- GitHub 仓库已有可用远端，当前为公开仓库且无已有 Release；发布规划从 v0.1.0 开始，实施时再次核对远端状态与 runner 可用性。
- 规划发布到本地 tracker，不创建 GitHub Issues；GitHub 用于 CI、构建产物和正式 Release。
- 参考依据：Tauri 官方框架、剪贴板和 GitHub 发布文档；Chrome 官方 Bookmarks API；GitHub 官方 hosted runner 文档；仓库 Emil Kowalski 设计技能与协作规则。实施前按对应平台的当前 API 确认细节。
