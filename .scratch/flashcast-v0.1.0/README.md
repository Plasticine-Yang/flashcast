# Flashcast v0.1.0 开发计划

Status: ready-for-agent
Category: enhancement

用户于 2026-10-01 确认本计划。Spec 与 18 张独立 ticket 已发布到本地 tracker，初始状态为 ready-for-agent，分类为 enhancement。当前可立即开始的任务为 01，其余任务在声明的依赖完成后进入可开发范围。

[阅读完整 Spec](spec.md)

## 测试边界

以宿主的查询和命令入口为主，从用户操作验证真实工作区、索引、历史存储与结果；仅在系统和外部环境适配边界控制替身。真实平台检查单独记录。UI 通过手动或浏览器交互验证，不添加 UI 单元测试。

## 首版范围与技术边界

- 最终交付包括全部已讨论功能和实际公开的 v0.1.0 Release，启动器演示只是第一切片。
- 默认紧凑列表，长内容和媒体按需展开预览；高频键盘操作无动画。
- 视频按文件处理，文件引用与已保存副本区分；任意应用私有格式不承诺全量恢复。
- Git 同步支持无冲突快进与推送；分叉、未提交修改和冲突保留内容并引导外部处理。
- CI 真实平台检查、构建结果和未覆盖的桌面能力分别展示；签名状态如实记录。

## Ticket 列表

1. [01: 在 Linux 唤起、搜索并打开软件，接入三平台 CI](issues/01-linux-launcher.md) — 依赖：None (can start immediately)。
   交付：用户在当前 Linux 桌面通过快捷键或备用入口打开 Flashcast，输入软件名、选择结果并启动真实软件；每次提交获得三平台构建结果。

2. [02: 在 Windows 搜索并打开软件](issues/02-windows-launcher.md) — 依赖：01。
   交付：Windows 用户通过同一个主窗口搜索和打开本机软件，并获得符合 Windows 环境的快捷键与错误反馈。

3. [03: 在 macOS 搜索并打开软件](issues/03-macos-launcher.md) — 依赖：01。
   交付：Apple Silicon 和 Intel Mac 用户通过同一个主窗口搜索、启动本机应用，获得准确的快捷键及权限状态。

4. [04: 从 CI 下载三平台候选安装包](issues/04-candidate-installers.md) — 依赖：01。
   交付：用户和维护者能下载对应提交的候选安装包，在开发过程中安装 Flashcast 并反馈实际平台行为。

5. [05: 关联本地 Git 配置工作区并保存设置](issues/05-local-config-workspace.md) — 依赖：01。
   交付：用户通过设置关联现有本地 Git 仓库，或初始化新工作区；修改快捷键等设置后立即生效、重启保留，并能通过编辑器维护配置。

6. [06: 安装主题插件并切换外观](issues/06-theme-plugins.md) — 依赖：05。
   交付：用户在设置中管理主题插件，切换浅色、深色或跟随系统，并可安装本地主题包；所选主题随配置工作区保存。

7. [07: 通过备忘录插件管理带标签的常用内容](issues/07-memo-management.md) — 依赖：06。
   交付：用户输入备忘录进入官方插件，创建、编辑、删除和搜索带多个标签的文字内容，预览或复制它；内容保存为工作区中的 Markdown。

8. [08: 在首屏按标签找到备忘录并粘贴到原应用](issues/08-memo-tag-paste.md) — 依赖：02, 03, 07。
   交付：用户在其他应用中唤起 Flashcast，输入备忘录标签、选择内容并按回车，将内容粘贴回原应用。

9. [09: 保存、搜索并恢复文字剪贴板历史](issues/09-text-clipboard-history.md) — 依赖：08。
   交付：用户启用剪贴板插件后，复制的文字被后台保存；输入剪贴板或剪切板搜索历史，回车粘贴，并能控制保留的数据。

10. [10: 保存、预览并恢复图片剪贴板历史](issues/10-image-clipboard-history.md) — 依赖：09。
   交付：用户复制图片后能从历史中看到缩略图和尺寸，查看完整预览，并在重启或来源消失后重新粘贴。

11. [11: 保留并恢复富文本的多种剪贴板格式](issues/11-richtext-clipboard-history.md) — 依赖：09。
   交付：用户复制富文本后，历史将同一次复制的纯文本与受支持的 HTML/RTF 格式关联保存，恢复时让目标应用选择合适格式。

12. [12: 保存文件与视频文件引用或副本并恢复](issues/12-file-video-clipboard-history.md) — 依赖：09。
   交付：用户复制文件或视频文件后可搜索名称、检查来源，并选择保存本机副本；回车恢复文件列表以便粘贴到支持文件的目标。

13. [13: 关联 Chrome profile、搜索书签并在 Chrome 打开](issues/13-chrome-bookmarks.md) — 依赖：07。
   交付：用户选择本机 Chrome profile，输入中文或英文关键词进入书签搜索，按标题、网址或目录找到书签，回车在选定 Chrome profile 打开。

14. [14: 从远端 Git 仓库克隆并启用配置工作区](issues/14-clone-config-workspace.md) — 依赖：05。
   交付：用户在新设备填写远端仓库与目标目录，克隆配置并切换到校验通过的工作区，恢复设置、主题和备忘录。

15. [15: 查看配置变更并创建 Git 提交](issues/15-review-commit-config.md) — 依赖：05。
   交付：用户修改设置或备忘录后，在应用中检查工作区的变更，明确选择提交内容并创建 Git 提交。

16. [16: 安全拉取、推送配置并处理同步阻塞](issues/16-sync-config-safely.md) — 依赖：14, 15。
   交付：用户将已提交配置推送远端，或快进拉取另一台设备的修改；遇到离线、鉴权失败、脏工作区、分叉或冲突时保留内容并看到处理指引。

17. [17: 展示平台能力状态并完成首版兼容性验收](issues/17-platform-capabilities.md) — 依赖：04, 10, 11, 12, 13, 16。
   交付：用户能在设置查看运行环境、权限与能力状态；维护者获得候选版本的平台检查证据，明确哪些行为通过、失败或未覆盖。

18. [18: 发布带三平台安装包的 v0.1.0 GitHub Release](issues/18-publish-minor-release.md) — 依赖：17。
   交付：下载用户可以在正式 GitHub Release 获取 v0.1.0 的全部首版目标安装包、SHA256 校验值和中文说明，追溯到已完成验证的代码。

## 发布约定

使用配置好的本地 Markdown tracker：一个 spec、每张实现 ticket 一个文件，编号按依赖顺序排列。当前提交发布规划；实现 ticket 开发与适用验证完成后流转为 done，并与实现一起提交。GitHub Release 的完成条件是实际公开发布 v0.1.0 及全部必需产物。
