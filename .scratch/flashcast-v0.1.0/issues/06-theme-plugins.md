# 06: 安装主题插件并切换外观

Status: ready-for-agent
Category: enhancement

**What to build:** 用户在设置中管理主题插件，切换浅色、深色或跟随系统，并可安装本地主题包；所选主题随配置工作区保存。

Blocked by: 05

- [ ] 建立可识别插件标识、种类、版本和启用状态的插件清单，默认主题通过该清单加载。
- [ ] 默认提供浅色、深色和跟随系统，本地主题包可校验、安装、选择和移除。
- [ ] 主题为声明式数据，使用统一颜色、字体、间距、圆角、阴影和状态语义，不运行主题代码。
- [ ] 切换后搜索、列表、预览和设置保持可读，焦点与选中状态可辨识，布局和操作位置稳定。
- [ ] 无效主题显示原因并保留可用外观；重启与工作区切换后正确恢复。
- [ ] 不让主题改变高频键盘操作的无动画规则，尊重减少动态效果设置。
- [ ] 手动或浏览器交互检查全部主题和系统缩放，不添加 UI 单元测试；通过宿主入口检查主题配置保存。
- [ ] 适用验证完成后更新正式 ticket 为 done，与实现一起创建中文 Git commit。

## Comments

此切片用真实主题管理建立共享插件标识、版本及清单；不把插件机制单独拆成无用户行为的基础层 ticket。
