# 16: 安全拉取、推送配置并处理同步阻塞

Status: ready-for-agent
Category: enhancement

**What to build:** 用户将已提交配置推送远端，或快进拉取另一台设备的修改；遇到离线、鉴权失败、脏工作区、分叉或冲突时保留内容并看到处理指引。

Blocked by: 14, 15

- [ ] 设置显示分支、远端、待提交/待同步状态，支持明确触发拉取与推送。
- [ ] 无冲突的快进拉取和推送成功，拉取后的有效设置、主题与备忘录重新加载。
- [ ] 复用远端关系与凭证管理，离线和鉴权失败不影响本地搜索、插件和设置使用。
- [ ] 未提交修改、分叉、冲突或已有进行中的 Git 操作显示阻塞原因，保留所有内容与现有暂存状态，不强推或自动丢弃。
- [ ] 提供外部处理指引与重新检测入口；处理后可恢复同步，不要求内置三方合并编辑器。
- [ ] 经宿主入口使用临时真实仓库和 bare 远端验证推送、快进、分叉、脏工作区及错误保护。
- [ ] 手动或浏览器交互检查同步状态；适用验证完成后更新正式 ticket 为 done，与实现一起创建中文 Git commit。
