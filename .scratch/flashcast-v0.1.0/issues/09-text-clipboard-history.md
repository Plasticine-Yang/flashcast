# 09: 保存、搜索并恢复文字剪贴板历史

Status: ready-for-agent
Category: enhancement

**What to build:** 用户启用剪贴板插件后，复制的文字被后台保存；输入剪贴板或剪切板搜索历史，回车粘贴，并能控制保留的数据。

Blocked by: 08

- [ ] 两个关键词进入同一插件，后台捕获文字并本机持久化，重启后可搜索、预览和粘贴。
- [ ] 数据模型按一次复制事件保存格式集合、时间、摘要和附件引用，可扩展到图片、富文本及文件。
- [ ] 重复内容去重，Flashcast 恢复历史不会导致自身监听循环和重复条目。
- [ ] 支持置顶、删除、清空、暂停/恢复记录以及保留期限和容量配置；停用插件停止后台活动。
- [ ] 历史与索引保留在本机，配置工作区只保存可迁移偏好。
- [ ] 捕获失败、存储失败和容量限制有准确状态，粘贴复用原应用恢复与复制回退。
- [ ] 非 UI 验证覆盖真实持久化、去重、暂停、过期与删除行为；平台监听与读写在可执行环境真实检查。
- [ ] 适用验证完成后更新正式 ticket 为 done，与实现一起创建中文 Git commit。
