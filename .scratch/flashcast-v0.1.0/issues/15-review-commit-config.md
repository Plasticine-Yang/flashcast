# 15: 查看配置变更并创建 Git 提交

Status: ready-for-agent
Category: enhancement

**What to build:** 用户修改设置或备忘录后，在应用中检查工作区的变更，明确选择提交内容并创建 Git 提交。

Blocked by: 05

- [ ] 设置展示工作区变更、文件差异与提交状态；能够输入提交说明并创建真实提交。
- [ ] 提交范围明确且可选择，不默认纳入无关文件或用户已有暂存修改。
- [ ] 提交后状态刷新，已有配置和备忘录继续正常使用，提交失败不丢失修改。
- [ ] 无变更、Git 环境不可用、用户身份未配置和工作区异常有明确反馈。
- [ ] 从宿主入口在临时真实仓库验证变更、选择范围、提交内容与错误保护，不仅检查 Git 命令字符串。
- [ ] 手动或浏览器交互验证差异与提交流程；适用验证完成后更新正式 ticket 为 done，与实现一起创建中文 Git commit。
