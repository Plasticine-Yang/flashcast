# Flashcast v0.3.0：电弧主题与统一插件规范

选定石墨结构和电弧配色，完成正式产品搜索、预览和设置改版。主题、深浅偏好和表面风格独立；所有新主题必须包含深浅两套，风格由主题声明，不强制玻璃。每主题记住风格，全局减少透明度提供实底回退。功能插件沿用宿主统一结果、预览、操作和设置语义。

统一插件契约记录 API 版本、宿主兼容范围和配置版本；新主题安装严格校验，旧工作区主题只作兼容读取。主题仍为声明式数据，功能插件运行方式暂沿用编译注册，不声称提供第三方代码执行 SDK。

交付包括规范、样例、迁移、宿主入口集成验证、浏览器实画检查，以及实际公开的 v0.3.0 minor Release 和三平台五种安装包、SHA256。
