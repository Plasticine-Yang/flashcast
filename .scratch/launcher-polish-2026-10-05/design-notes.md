# 设计说明

沿用此前已选定的「电弧」方向：结构清晰、克制的石墨与蓝色，服务于键盘启动器的快速取用。复用现有主题变量。

## 主要任务与改动

- 功能插件用图标、用途、关键词和单一开关组成紧凑列表。汇总启用数量，去掉重复的状态徽章和启用/停用按钮。
- 剪贴板以真实捕获状态和历史为主。保留期限、容量与文件存储说明折叠展示，保留必需的路径和失败原因。
- 搜索页的备忘录采用列表与正文两列，管理操作靠近正文。标签与插件关键词冲突时优先选中正文，仍保留插件入口。
- 编辑时收起范围条与新建工具栏，给表单留空间；保存按钮持续可见。Ctrl+Enter 保存，Escape 取消。提交失败保留输入。编辑期间禁用搜索与设置入口，避免误切换丢失草稿。
- 长正文独立滚动，粘贴和删除操作保持可见。窄窗口下剪贴板历史的操作另起一行。

## 图标

十个独立 SVG 方向：01 切光、02 疾行 F、03 快门、04 双轨、05 投射、06 指令、07 电路环、08 折带、09 负形电光、10 FC 联结。它们不是同一轮廓的颜色变体。

推荐 02：字母 F 与前进方向相关，便于建立产品识别。推荐 08：连续折带在小尺寸与单色下轮廓简洁。01 最直观地继承闪电意象。03 的内部分片、10 的联字在 16px 下细节更紧，应按使用场景取舍。

icons/style-explorer.html 提供并排、单张、深浅背景及 16/24/32/48px 比较；当前图标作为额外基线，不计入十版。icons/board.svg 和 evidence/icons-board/page.png 是总览。用户已选定 01「切光」。scripts/dev/generate-icons.py 生成对应 PNG/ICO/ICNS 和 SVG；浏览器与底部品牌标记同步采用该形状，托盘继承默认应用图标。

## 独立视觉评审

隔离评审者只看截图、任务和视口约束。备忘录初版评分 7.5/10；设置精修按协议不评分。指出小窗口编辑区保存按钮离屏、编辑快捷键误导，以及剪贴板窄屏操作挤压正文。

已分别修正：编辑时收起重复工具栏并调整表单布局；切换操作栏提示并隔离全局按键；历史操作窄屏独立成行。主 Agent 查看了修正后的 480×420、640×420 与 200% 证据。没有追加独立评分，不将自检写成提分。

剩余视觉取舍：短正文留下较大阅读留白；正式图标已按 01「切光」生成，已安装程序需后续打包更新才采用新资源。
