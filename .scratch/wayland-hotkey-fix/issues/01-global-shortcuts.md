# 修复 Wayland 全局快捷键唤起

Status: done
Category: bug

## 问题

Wayland 会话被 LinuxHotkeyManager 直接拒绝，即使桌面已提供 XDG GlobalShortcuts 门户，也无法用快捷键唤起 Flashcast。

## 验收

- Wayland 通过门户声明应用身份、申请并保留快捷键会话；X11 保留原后端。
- 激活事件携带一次性令牌到主线程窗口；不会把其它会话的事件当成本次按键。
- 授权过程不阻塞 GTK；取消、空绑定、门户不可用和超时如实反馈。
- 失败保留旧绑定，迟到结果不覆盖新设置；注销关闭会话并停止派发。
- 显示实际系统绑定，等待授权有明确提示；设置提示系统最终决定按键。
- 完成 Cargo 与浏览器检查，准备 v0.3.1 版本元数据和发布说明。
