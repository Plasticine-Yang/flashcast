# Flashcast 插件页面：十版交互探索

## 任务与方向

Flashcast 是键盘优先的桌面启动器。首屏主要任务是找到软件或插件，Enter 进入，继续在插件内部搜索和操作。本轮探索交互结构，保留已选「01 切光」图标和既有蓝色主操作，不以十套颜色冒充十种交互。尚未选定生产方向。建议先体验 01 与 07：01 减少视线位置变化，07 让鼠标管理动作持续可见；02 适合强调搜索范围和返回路径。

参考行为来自 [Raycast Clipboard History](https://manual.raycast.com/clipboard-history)、[Raycast Snippets](https://manual.raycast.com/snippets) 与 [Alfred Clipboard History](https://www.alfredapp.com/help/features/clipboard/)。借鉴命令入口、历史搜索及快捷键配置，页面构图围绕 Flashcast 的实际桌面小窗口重新组织。

| 编号 | 方向 | 首页与浏览 | 管理交互与取舍 |
| --- | --- | --- | --- |
| 01 | 顺手双栏 | 左侧结果、右侧内容，位置稳定 | 正文区域内联编辑；输入空间较紧 |
| 02 | 路径导航 | 独立路径栏，进入和返回范围明确 | 全页编辑；浏览上下文暂时退后 |
| 03 | 动作托盘 | 首页通栏列表，次级动作集中 | Ctrl+K 动作面板、居中编辑；管理多一步 |
| 04 | 内容画廊 | 首页双列卡片，插件结果有对象边界 | 抽屉编辑；识别对象直观，列表密度较低 |
| 05 | 紧凑清单 | 编号与行分隔，提高首屏数量 | 编辑对话框；阅读氛围更克制 |
| 06 | 焦点工作台 | 当前对象放大，窄列表给正文空间 | 阅读区域内联编辑；长标题需要换行 |
| 07 | 侧边动作 | 正文旁固定新建/编辑/删除操作轨道 | 编辑抽屉保留列表；牺牲一条窄栏宽度 |
| 08 | 分组目录 | 软件/插件、目录与日期分组 | 正文原位编辑；分组消耗部分列表高度 |
| 09 | 时间线 | 时间单独成列，复制与更新时间可扫读 | 全页编辑；每行留给标题的宽度减少 |
| 10 | 命令终端 | 编号、命令路径与等宽辅助文字 | 动作面板、编辑对话框；键盘感更强 |

这十版共用业务状态，仅布局、搜索上下文呈现和管理入口变化，便于比较操作手感。剪切板按用户明确约束始终是左侧历史、右侧完整文字/图片，不让候选改成只有列表。对比页另有一张当前页面截图，作为基线，不计入十版。

## 体验入口

打开 `style-explorer.html`，点每张卡片的「单张查看」后在页面内操作。01–10 可直接打开对应编号 HTML。对比页已经内联 Alpine、图片和图标，独立文件无需访问网络；编号页面使用同目录 assets。

1. 首页输入 `bookmark`，Enter 进入 Chrome 书签。再输入 `Rust`，Enter 展示待打开的链接。
2. 首页输入 `回复`，先看到标签对应备忘录。首次 Enter 进入并保留搜索与选中项，再 Enter 展示待粘贴的完整正文。
3. 输入 `备忘录` 进入后操作新建、编辑与删除；03 的编辑/删除在底部动作面板里，07 在右侧操作轨道。标题或正文为空时保留草稿并提示；删除要求再次确认。
4. 输入 `剪切板` 进入，搜索 `截图` 查看图片，清空查询查看完整文字。正文过长可在右侧滚动。
5. 点设置，选择「剪切板」，配置记录、期限、容量和快捷键。快捷键在该区域下半部，可滚动到达。切换 Linux/Windows/macOS 查看平台默认值，也可给另外两个插件设置快捷键。
6. 设置后返回插件仍保留原搜索与选中项。Esc 取消当前确认、动作面板、结果预览、编辑或返回上层；方向键选择，Enter 执行。

## 实际接入边界

原型的数据和变更只在当前页面内存中，刷新会恢复。打开链接与粘贴呈现操作目标，不实际启动 Chrome、操作真实剪切板或注册系统全局快捷键。剪切板图片使用上一轮 Flashcast 页面截图。容量和期限在原型中演示配置值，不执行历史清理。

当前生产契约尚无统一插件命令/全局快捷键注册能力。后续选版后的实现需要按已对齐设计扩展通用命令描述：稳定 command ID、平台默认快捷键、用户覆盖、冲突/注册状态，以及进入插件页面的目标。原型按插件 ID 演示三个页面命令；快捷键匹配与冲突判断共用同一机制，剪切板不是单独一条特殊跳转逻辑。默认 Linux/Windows 为 Ctrl+Alt+C；macOS 为 Control+Command+C。

本轮生产代码只修正设置导航与标题为「剪切板」。真实应用里历史迁移到插件页、删除保存本机副本入口及系统快捷键接入，将在交互选定后实施。本轮没有发布或替换安装包。

## 视觉整理与动效

删掉顶部快速访问/备忘录/Chrome 书签 Tab、设置里的历史列表、保存本机副本入口和关于存储路径的大段说明。删去首页预览中重复出现的对象用途；标签命中时保留正文内容。对象名称、当前范围、内容、记录状态和主动作保留。

三处基础反馈是窗口出现 170ms、结果选中背景 100ms、正文/编辑区域出现 140ms；按钮按下轻微反馈。系统减少动态效果时关闭这些动效。保持主搜索输入、结果对象、选中正文的层级，无额外装饰图像。

- 浏览器逐版验证标签命中两次 Enter，全部显示正确的进入页和粘贴目标。01 验证完整新增、校验失败保留草稿、编辑与 Ctrl+Enter 保存、删除确认；02/03/04/07 验证全页、弹窗、抽屉、动作托盘和侧边入口。03 删除确认修正后再走查通过。
- 01 验证 bookmark 入口、Rust 过滤和打开目标，剪切板文本与图片、设置返回，快捷键保存/恢复默认及跨插件冲突。配置 Ctrl+Alt+J 后分别验证能直达剪切板和备忘录，证明通用命令跳转。原型设置里的暂停记录不妨碍进入现有历史。

- 对比页单张模式实操进入剪切板、查找截图并验证 data URI 图片已加载，证明原型交互和图片不依赖网络。

- `evidence/shortcut-settings/page.png` 展示滚动到快捷键配置；实际应用设置名称也经浏览器检查。
