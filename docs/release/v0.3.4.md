# v0.3.4

本次 patch Release 按 03「动作托盘」重做插件页面：主搜索中选择插件再回车进入，功能操作和配置分开。保留用户选定的「切光」图标。

## 变化

- 主搜索移除快速访问、备忘录和书签 Tab。插件作为搜索结果；输入 bookmark、bookmarks、书签或原有别名均可找到 Chrome 书签入口。回车进入全部书签，继续按标题、网址或目录过滤；清空查询仍留在插件，Esc 恢复进入前的查询和选中项。插件列表不再被 50 条截断。
- 备忘录标签结果优先展示；首次回车进入并保留匹配选中项，第二次回车粘贴正文。页面内可新建、编辑和确认删除；失败保留草稿，保存和置顶后预览跟随同一选中对象。
- 剪切板拥有独立插件页面，左侧历史、右侧完整文字或图片预览。动作托盘提供置顶、删除、清空；配置页只保留启停、暂停、保留期限、容量和快捷键，名称统一为「剪切板」。移除新增本机文件副本入口，兼容已有副本数据。
- 插件统一贡献稳定页面命令、平台默认快捷键和用户覆盖。剪切板默认 Linux／Windows `Ctrl+Alt+C`，macOS `Control+Command+C`；可保存、清除和恢复默认。显示待授权、系统错误及实际生效按键，插件停用即注销，迟到授权不能重新启用已停用的命令。
- Wayland 后台捕获不再通过会夺取前台焦点的读取方式循环探测；不支持 data-control 时停止捕获并显示原因，已有历史仍可使用。记录错误也显示在插件页面。
- 统一文档补充插件页面与命令贡献。功能插件仍随宿主编译注册；可引用独立仓库中的受信任 Rust crate，未引入任意第三方代码下载执行机制。

## 验证与限制

- 本地 Cargo 工作区 384 项通过、8 项忽略；浏览器连续操作 58 项通过；生产前端构建、Linux 原生构建及发布入口 15 项拒绝条件检查通过。流水线溯源在发布核验后追加。
- 浏览器覆盖显式进入／返回、标签两次回车、CRUD、同名标签、失败重试、IME、托盘、完整图片、惰性富文本、文件恢复、剪切板启停和插件／主快捷键设置衔接，以及深浅模式与风格切换；没有新增 UI 单元测试。
- 独立视觉评审初版 8/10，已删除重复行类型、标签前缀、预览操作说明与编辑快捷键提示，修正焦点颜色；修正后未重复评分。
- 本机 GNOME Wayland 未提供 data-control，后台历史记录如实停用；自动粘贴因当前平台能力不支持而降级为复制后手动粘贴。门户实际组合由系统授权决定。本次没有把浏览器模拟、平台编译或注册状态当作物理快捷键／自动粘贴实测。
- Windows 无 Authenticode 签名，macOS 为 ad-hoc 签名、未公证；安装限制沿用 v0.3.3。
