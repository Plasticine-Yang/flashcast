# Flashcast v0.3.2

本次 patch Release 将默认唤起快捷键调整为 **Alt + 空格**，macOS 对应 **Option（⌥）+ 空格**。

## 变更

- 新建配置或未指定快捷键时，默认使用 `Alt+Space`。
- 设置输入提示和浏览器模拟宿主同步使用新默认值。
- 已有配置保留原来的快捷键，可在「设置 → 全局快捷键」修改为 `Alt+Space`。
- Wayland 下实际生效按键仍以系统授权绑定为准。

## 验证与限制

- 本地 `cargo test --workspace`、`cargo build -p flashcast`、`pnpm build` 通过。
- 74 项浏览器交互检查通过，包含发布前连续操作走查、配置保存与重试、插件入口和同步后重新加载。检查使用 `CHOKIDAR_USEPOLLING=1` 绕过本机文件监听数量限制。
- 15 项发布入口检查通过。
- 默认设置解析为 `Alt+Space`，后端映射为 Alt 修饰键与 Space；旧配置的 `Ctrl+Alt+Space` 在 JSON/TOML 读写后保持不变。
- 原生按键唤起需要对应桌面环境验证；浏览器检查和后端键码映射检查不作为 macOS 原生按键实测证据。

Windows 未配置证书时未做 Authenticode 签名；macOS 为 ad-hoc 签名且未公证，安装方式和签名限制沿用 v0.3.1。
