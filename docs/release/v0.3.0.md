# Flashcast v0.3.0

Flashcast 是键盘优先的桌面启动器。本次 minor Release 将正式产品更新为石墨布局与电弧配色，并建立统一插件契约。

## 本版本包含

- **电弧外观**：冷静的灰蓝底色与闪电蓝强调，完整浅色／深色设计。搜索结果使用通栏，备忘录、书签和剪贴板内容按需在底部预览；设置统一采用分组目录、语义图标及清晰层级。
- **独立外观偏好**：设置 → 外观主题，可分别选择主题、跟随系统／浅色／深色、当前主题提供的表面风格。电弧提供毛玻璃、液态玻璃和实底；风格按主题记忆。全局「减少透明度」使用实底，保留所选风格。
- **原生窗口材质**：Windows 接入 Acrylic，macOS 接入系统窗口模糊；效果不可用时降级实底。Linux 当前使用实底。液态玻璃是模糊、亮边与稳定阅读层组成的外观近似，不是 Apple 原生 Liquid Glass，也没有真实几何折射。
- **主题规范 v2**：新安装／更新强制提供浅色和深色，并分别校验。风格由主题声明；纸面等非玻璃主题无需提供玻璃。一种风格时隐藏风格切换器。主题仍为声明式数据，不执行代码。
- **共同插件契约 v1**：主题与功能插件共用 API 版本、宿主兼容范围、配置版本；不兼容的注册／安装被拒绝。功能插件继续随应用编译，使用宿主结果、预览、操作和设置语义。本版没有第三方代码下载／执行 SDK。
- **保存反馈修复**：备忘录保存失败保留完整草稿和编辑状态，成功后重新读取列表才清空表单。首页软件优先，维护命令保留在后面；命令的回车提示改为「执行」。
- **配置与恢复**：外观偏好在关联的配置工作区中保存和同步；未关联时保存到设备目录。旧工作区的 v1 主题继续可读；只有主题标识的旧配置使用新增字段的默认值。无效配置保留上一次可用外观，主题升级保存失败恢复原包。停用／移除当前自定义主题回到电弧。

插件规范及完整双模式、非玻璃模板见 [docs/plugins](https://github.com/Plasticine-Yang/flashcast/tree/v0.3.0/docs/plugins)。开发者可使用 `theme-template` 生成和校验主题。

## 安装

| 平台 | 安装包 |
| --- | --- |
| Linux x64 | `Flashcast_0.3.0_amd64.AppImage`、`Flashcast_0.3.0_amd64.deb` |
| Windows x64 | `Flashcast_0.3.0_x64-setup.exe` |
| macOS Apple Silicon | `Flashcast_0.3.0_aarch64.dmg` |
| macOS Intel | `Flashcast_0.3.0_x64.dmg` |

Linux：AppImage 添加可执行权限后运行；无 FUSE 时可用 `--appimage-extract-and-run`。deb 可用系统包管理器安装。Windows：运行按当前用户安装的 exe。macOS：打开 dmg，将应用拖入「应用程序」。下载后可用 `SHA256SUMS.txt` 核对安装包。

当前流水线在未配置证书时生成未做 Authenticode 签名的 Windows 包，以及 ad-hoc 签名、未公证的 macOS 包；系统可能拦截首次启动。Windows 可在核对来源后选择「更多信息 → 仍要运行」，macOS 可右键应用选择「打开」或在「隐私与安全性」中放行。本次构建的签名证据以对应 CI 安装包检查报告为准。

## 验证范围与已知限制

本地已通过 `cargo test --workspace`、TypeScript 检查和生产构建；宿主入口覆盖深浅／风格独立、保存重启、外部重载、双模式与契约拒绝、写入失败和升级回滚。UI 用浏览器实际交互及 640×420、480×420、200% 截图检查，没有添加 UI 单元测试。

tag 流水线在 Linux x64、Windows x64、macOS arm64、macOS x64 上重跑编译、宿主测试、平台接口及安装包检查，完整生成五个安装包后才公开发布。发布溯源与校验值由该流水线追加。

- Windows／macOS 的系统模糊接入由跨平台编译验证；没有在真实 Windows／macOS 桌面人工验收材质或真实 Tauri webview 的画面。本次浏览器材质截图不能证明原生窗口视觉一致。
- Linux Wayland 的全局快捷键、自动粘贴和全局前台应用身份仍受平台限制；可从托盘打开，粘贴会降级为复制后手动粘贴。X11 的接口成功不能推断 Wayland 支持。
- Windows／macOS 端到端自动粘贴、真实托盘点击和输入法行为未在人工桌面复核；现有能力边界记录见 [平台能力报告](https://github.com/Plasticine-Yang/flashcast/blob/v0.3.0/docs/platform/capability-report.md)，该报告的历史数字不作为本版新验证结果。
- 原生玻璃效果还会受系统版本、无障碍设置及 GPU 支持影响；失败时使用主题的不透明回退，用户偏好仍保留。
