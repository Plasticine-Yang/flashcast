# Flashcast v0.3.1

本次 patch Release 修复 Linux Wayland 下无法注册全局快捷键的问题。

## 修复内容

- Wayland 接入 XDG GlobalShortcuts 门户，声明与桌面文件一致的应用身份，在系统授权后保留快捷键会话并监听唤起事件。X11 继续使用原有后端。
- 使用系统返回的一次性激活令牌显示并聚焦窗口。拒绝、取消、空绑定、门户不可用和超时显示具体原因。
- 授权在后台等待，启动和设置窗口保持可操作；设置更新失败保留旧绑定，迟到的授权结果不会覆盖新设置。注销关闭门户会话并停止事件派发。
- 首页和设置页显示等待授权状态，实际按键以系统返回的绑定为准。用户保存的首选组合与系统实际按键分别保留，避免显示名称覆盖 settings.toml 配置。
- deb 随包提供门户身份文件；便携 AppImage／开发运行按需创建不显示在菜单的用户桌面条目，支持从终端启动。

## 使用

首次启动时，在系统弹窗中授权「打开 Flashcast」并确认按键。已有绑定可在桌面的快捷键设置中修改。没有 GlobalShortcuts 门户的桌面仍可通过托盘打开，或配置运行 `flashcast` 的系统自定义快捷键。

## 安装包

| 平台 | 安装包 |
| --- | --- |
| Linux x64 | `Flashcast_0.3.1_amd64.AppImage`、`Flashcast_0.3.1_amd64.deb` |
| Windows x64 | `Flashcast_0.3.1_x64-setup.exe` |
| macOS Apple Silicon | `Flashcast_0.3.1_aarch64.dmg` |
| macOS Intel | `Flashcast_0.3.1_x64.dmg` |

下载后用 `SHA256SUMS.txt` 核对安装包。安装方式和签名限制沿用 v0.3.0：Windows 在未配置证书时未做 Authenticode 签名，macOS 为 ad-hoc 签名且未公证。

## 验证与限制

- 本地 `cargo test --workspace`、原生宿主构建、前端生产构建、74 项浏览器交互检查、Windows/macOS 平台适配层跨目标检查及 15 项发布入口检查通过。
- 隔离 D-Bus 总线穿透真实门户适配，验证应用身份先于会话创建、成功授权、取消、空绑定、门户缺失、事件会话隔离、激活令牌传递、注销后停止回调。此检查使用门户服务替身，不作为实际桌面按键证据。
- GNOME 50.1 / Wayland 真实门户已完成用户授权，`Ctrl+Alt+Space` 注册与注销实测通过。
- 原生按键唤起和输入焦点已发起用户走查，暂未收到结果；不计入自动化通过项。Linux deb 本地构建通过，已确认包内包含门户身份文件。
- 其它 Wayland 桌面的实际唤起仍需对应环境验证，不能用 GNOME 的结果推断全部桌面支持。快捷键支持不改变全局前台应用身份和自动粘贴的能力边界；这些操作仍可能降级为复制后手动粘贴。

同一提交的完整 CI 与发布流水线成功后，发布溯源和五个安装包的 SHA256 由流水线追加。
