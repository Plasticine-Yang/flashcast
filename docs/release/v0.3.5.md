# v0.3.5

本次 patch Release 汇总 [v0.3.4](https://github.com/Plasticine-Yang/flashcast/releases/tag/v0.3.4) 之后的全部产品变化：简化备忘录操作，统一搜索与设置控件，修复 Chrome 账号书签读取，并为没有 data-control 的 GNOME Wayland 会话提供剪切板记录扩展。

## 变化

- 备忘录新建后直接输入正文，标签可选。列表摘要来自正文首个非空行，不再要求单独填写标题；空白正文不能保存。兼容已有 Markdown 备忘录，编辑时按正文更新摘要，完整正文与换行保留。
- 备忘录预览旁直接提供编辑、删除。移除重复标题和粘贴按钮，回车粘贴与动作菜单仍可使用；保存后列表、选中项与预览同步。保存失败保留正文和标签，错误只显示一次，修正后可重试。
- 主搜索移除逐行回车装饰和底部重复按键提示。设置与插件页面统一返回图标、点击区域和区块间距；Chrome 设置精简重复状态，来源路径与进一步排查说明按需展开。
- 文本、密码、数字、复选框、正文、按钮等控件统一外观和键盘焦点。数字字段移除默认箭头装饰，保留上下键调值；期限与容量的整数及范围错误在页面内显示。凭据输入增加持续可见的字段标签。
- 删除与清空确认按钮保持间距；确认框限制 Tab 焦点范围，取消或 Escape 返回后恢复键盘入口。深浅模式、窄窗口与高对比焦点继续支持。
- Chrome 同时读取本地 `Bookmarks` 与账号 `AccountBookmarks`。仅有账号书签的用户也可发现、关联和搜索；两类书签使用独立标识，文件更新或删除会刷新索引，读取失败保留已有索引并显示原因。修复“Chrome 有书签，Flashcast 显示 0 条”的情况。
- GNOME Wayland 可通过配套 Shell 扩展记录文本、HTML、RTF、PNG 和文件引用，无需创建会夺取前台焦点的读取窗口。暂停、停用插件、锁屏或 Flashcast 退出后停止读取并清空桥接队列；历史继续由 Flashcast 本机保存。扩展断开时显示原因，已有历史仍可用。

## GNOME Wayland 安装说明

Linux 安装包之外，GNOME 会话需要单独安装配套 Shell 扩展。该扩展与安装脚本随本版本源码提供；在此 Release 下载 **Source code (zip)** 或 **Source code (tar.gz)**，解压后在源码根目录执行：

```bash
bash scripts/gnome/install-clipboard-bridge.sh
```

安装或更新后退出登录再登录，启动 v0.3.5，启用剪切板插件并取消暂停，再在其它应用复制内容。脚本保留其它扩展设置，不会自动注销或重启桌面。普通 Ctrl+C / Ctrl+V 不需要这个扩展。

扩展声明兼容 GNOME 45–50；本次实测 GNOME 50.1。其它版本需验证。详情见[本版本 GNOME 剪贴板文档](https://github.com/Plasticine-Yang/flashcast/blob/v0.3.5/docs/platform/gnome-clipboard.md)。X11 和支持 data-control 的 Wayland 桌面沿用原有记录方式。

## 验证与限制

- Chrome 宿主回归 26 项与剪贴板宿主回归 40 项通过；平台用户发现夹具 7 项通过、2 项环境检查忽略。本机关联用户的 19 条账号书签已通过只读检查成功索引。
- GNOME 桥接在独立 D-Bus 会话中通过真实 Mutter Selection、Rust 后端与宿主历史集成检查；独立 GNOME Shell 50.1 的默认及 Ubuntu 会话模式均通过扩展加载、捕获与 compositor 焦点检查。
- Headless Shell 检查使用自建选区内容，没有真实输入 serial，不能代表真实登录会话中普通应用的 Ctrl+C 流程。真实桌面重新登录后的复制、锁屏，以及其它 GNOME 版本与应用格式组合仍需实机确认。
- 界面已完成 640×420、480×420、深浅色及关键 200% 细节检查；发布前连续浏览器走查 58 项通过，覆盖正文编辑、失败重试、同名标签、范围切换后键盘执行、插件启停与模式／风格独立切换。浏览器使用模拟宿主，不代表原生全局快捷键或跨应用自动粘贴实测；没有新增 UI 单元测试。
- 本地 Cargo 工作区、生产前端构建、Linux 原生构建与发布入口 15 项拒绝条件检查通过。同 SHA 多平台 CI 与安装包核验记录在发布后追加。
- 不支持自动粘贴的平台仍使用复制后手动粘贴；系统快捷键授权取决于桌面门户。Windows 未配置 Authenticode 签名；macOS 使用 ad-hoc 签名、未公证，首次运行仍可能受 SmartScreen 或 Gatekeeper 限制。
