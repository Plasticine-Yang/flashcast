# Flashcast v0.3.3

本次 patch Release 修复 Wayland 应用身份注册失败，并让 GNOME 的 Alt+Space 冲突可以在设置页中发现和处理。

## 变更

- 「设置 → 全局快捷键」区分目标按键与 GNOME 系统绑定，检测窗口菜单对 Alt+Space 的占用。
- 支持确认后解除占用并重新绑定 Flashcast；保留其他按键与操作，修改前保存本机备份，可撤销。
- 自动处理失败时尝试恢复旧设置；系统不支持、设置只读或无法检测时提供手动步骤，系统已有 Ctrl+Alt+Space 绑定时，可一键使用当前绑定。
- 系统后来被再次修改时拒绝覆盖，避免撤销破坏用户的新选择。
- 修复开发运行和便携 AppImage 中失效桌面入口导致的 `App info not found`；检查实际可加载性并修复为有效程序路径。
- 改善开发监听隔离与按需缓存清理，避免编译产物耗尽文件监听额度。

## 验证与限制

- 本地 Cargo 工作区 375 项测试通过；8 项按环境或显式子进程/原生诊断规则忽略。新增 GNOME 宿主集成检查穿透真实 GSettings 和隔离 D-Bus，覆盖失败恢复、保留其他按键、撤销保护与不支持环境。
- 80 项浏览器交互检查通过，包含六项快捷键冲突连续操作检查；没有添加 UI 单元测试。
- `cargo build -p flashcast`、`pnpm build` 与 15 项发布入口检查通过。
- 本机真实 GNOME Wayland 的检测、解除与撤销通过，并恢复诊断前设置。物理 Alt+Space 唤起和输入焦点未作人工实测，不把系统绑定成功当作原生按键通过。
- 自动处理限于 GNOME Wayland 已授权绑定，且具备可写设置和重新绑定接口；其他桌面与旧系统提供现有注册错误或手动指引。

Windows 未配置证书时未做 Authenticode 签名；macOS 为 ad-hoc 签名且未公证，安装方式和签名限制沿用 v0.3.2。

同一提交的完整 CI 与发布流水线成功后，由流水线追加源码和资产 SHA256 溯源。
