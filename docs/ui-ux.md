# Flashcast UI/UX 设计规范

- 版本：v0.1（设计草案）
- 依据：[prd.md](./prd.md)
- 设计基线：深色玻璃拟态（Glassmorphism）+ 极简单列启动器；Inter 字体；键盘优先；高动效强度
- 本文档是 UI 的 Source of Truth：颜色、尺寸、动效、键盘行为均以这里为准

---

## 1. 设计目标

| 原则 | 含义 | 落到界面上 |
|---|---|---|
| 瞬时 | 按下快捷键到可用不超过 120ms | 窗口先出现再动画，入场动画不阻塞输入 |
| 单一焦点 | 任何时候只有一个输入框 | 全局搜索、插件搜索都复用同一个输入框 |
| 键盘优先 | 所有操作可无鼠标完成 | 选中态、焦点环、底部快捷键提示必须可见 |
| 流体但克制 | 动画表达层级变化，不做无意义装饰 | 只动 opacity / transform / filter，一次最多 2 个关键元素 |
| 平台原生 | 三端看起来都像"属于这个系统" | 毛玻璃、圆角、阴影、快捷键符号按平台适配 |

视觉基调：`#18181B` 近黑玻璃面板 + 琥珀色闪电强调色；信息层级低对比、内容高对比；无边框装饰、无渐变背景、无 3D 效果。

---

## 2. 设计假设（待确认）

1. 技术栈未定。本文以 Web 技术栈（Electron / Tauri WebView）描述实现，毛玻璃与全局快捷键需要原生能力配合。
2. 窗口固定尺寸 `720 × 480`，出现在当前显示器上方约 18% 处；不随内容自动变宽。
3. 以深色模式为主，浅色令牌只做兼容，不作为首发重点。
4. 剪贴板预览使用右侧浮层，不改变窗口宽度，避免三端窗口 resize 卡顿。
5. `esc` 分层退出：插件可先消费（如关闭预览），未消费时退出插件；设置页先返回插件主页。

毛玻璃在浅色桌面上的最差合成色约为 `#424245`，主文字仍有 ≈ 9:1，因此 `0.82` 是最低不透明度，不可再降低。

### 3.3 字体

- UI 字体：`Inter`（内置打包，避免 Linux 缺字），回退 `system-ui, -apple-system, "Segoe UI", "Noto Sans SC", sans-serif`
- 等宽：`JetBrains Mono`，仅用于 URL、路径、版本号
- 功能特性：`font-feature-settings: "cv11", "ss01"`，数字使用 `tnum`

| 角色 | 字号/行高 | 字重 | 字距 |
|---|---|---|---|
| 搜索输入 | 18 / 1.4 | 500 | -0.01em |
| 结果标题 | 15 / 1.3 | 500 | -0.01em |
| 结果副标题 | 12 / 1.35 | 400 | 0 |
| 分区标题 | 11 / 1.2 | 600 | 0.08em（大写或中文加字距） |
| 插件页标题 | 20 / 1.3 | 600 | -0.01em |
| 表单标签 | 12 / 1.4 | 500 | 0 |
| 正文字段 | 13 / 1.5 | 400 | 0 |
| 键帽提示 | 11 / 1 | 500 | 0.02em |
| Toast | 12 / 1.4 | 500 | 0 |

### 3.4 间距、圆角、层级

- 间距基数 4px，常用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。窗口内部左右边距 12，行内边距 12，垂直节奏 8。
- 圆角：窗口 18，行 10，预览面板 14，按钮 8，键帽 5，图标容器 8，应用图标 8。
- 阴影：`0 24px 80px rgba(0,0,0,0.55)`，高光描边 `inset 0 1px 0 rgba(255,255,255,0.06)`。
- 图标：Lucide，线性 1.5px；尺寸 `16 / 20 / 24 / 28 / 32`；应用图标 32，插件图标 28，输入框插件按钮 28。
- 禁止 emoji 当图标；插件未提供图标时用 `puzzle` 线性图标兜底。

## 4. 窗口与布局

### 4.1 窗口规格

| 项 | 规格 |
|---|---|
| 尺寸 | `720 × 480`，最小 `640 × 400` |
| 位置 | 当前显示器水平居中，距工作区顶部 18%（最高不超过 160px） |
| 层级 | 置顶、跨工作区显示、任务栏/Dock 隐藏、无标题栏 |
| 圆角 | 18px，Windows 11 取系统圆角上限 |
| 背景 | 深色毛玻璃 + 1px 内部描边 |
| 遮罩 | 全屏 `rgba(0,0,0,0.30)`，不模糊桌面（省性能，避免 Linux 抖动） |
| 多屏 | 使用鼠标所在屏；记住上次位置并校验是否在工作区内 |

平台兜底：

- macOS：`NSVisualEffectView`（hudWindow / dark）提供真实毛玻璃；CSS 只负责层级。
- Windows 11：优先 Acrylic/Mica；不可用时 `--fc-window-solid`。
- Linux：只有 KDE（KWin blur）等少数合成器支持窗口模糊。检测不到时用 `#18181B` 不透明底，保留描边与阴影；阴影由合成器绘制，无阴影时加 1px 描边。
- 系统开启"减少透明度"（macOS）或"透明效果关闭"（Windows）时，强制不透明。

### 4.2 主界面结构

```text
┌──────────────────────────────────────────────────────────┐  720 × 480
│  [⌕]  搜索应用、插件或命令                      [插件图标] │  60px
├──────────────────────────────────────────────────────────┤  1px
│  插件                                                    │  24px
│  ┌────────────────────────────────────────────────────┐  │
│  │ [◧] 剪切板    最近复制的内容…                  [↵] │  │  48px
│  └────────────────────────────────────────────────────┘  │
│  应用                                                    │  24px
│  ┌────────────────────────────────────────────────────┐  │
│  │ [◈] Chrome                            浏览器       │  │  48px
│  └────────────────────────────────────────────────────┘  │
│  ...                                                     │
├──────────────────────────────────────────────────────────┤  38px
│  ↵ 打开     esc 关闭     ctrl J/K 移动            ? 快捷键 │
└──────────────────────────────────────────────────────────┘
```

- 输入区 60px：搜索图标 20、间距 12、输入文字 18；右侧插件图标仅进入插件后出现。
- 列表区可滚动，一屏约 7 行；滚动条为 6px overlay，仅在滚动时出现。
- 底部 38px 为上下文快捷键条，按键帽 + 文案组合，最高 4 条；右侧固定 `?` 打开快捷键帮助浮层。

### 4.3 结果行 Anatomy

| 元素 | 规格 |
|---|---|
| 行高 | 48px，行间距 2px，圆角 10px，内边距 `0 12px` |
| 前置图标 | 32×32，圆角 8；应用用系统图标，插件用插件图标，书签用 favicon |
| 主标题 | 15/500，单行，`text-overflow: ellipsis` |
| 副标题 | 12/400 次文字，单行；应用=类别/路径，书签=URL，插件=关键字说明 |
| 尾部 | 选中时显示 `↵` 键帽；书签显示文件夹 chip；剪贴板显示"类型 · 相对时间" |
| 选中态 | `surface-selected` 背景 + 标题提亮至 600 字重；不使用彩色左边条（避免只靠颜色表达） |
| 匹配高亮 | 命中的字符用 `--fc-accent`、字重 600；不做背景色块 |
| 悬停 | 选中跟随鼠标；悬停 120ms 背景渐变 |
| 点击 | 单击即执行主操作（与 Raycast 一致） |

搜索更新时不做列表位移动画，避免输入抖动；结果直接替换，新行 80ms 透明度渐变。筛选导致的增删用 FLIP，仅 120ms。

### 4.4 焦点区域

```text
[ 搜索输入 ] ──ctrl+l──▶ [ 结果列表 ] ──ctrl+l──▶ [ 预览/详情 ]
      ▲                                                  │
      └──────────────────── ctrl+h ──────────────────────┘
```

- 输入框默认始终持有键入焦点；`ctrl+h/l` 切换的是"导航焦点"（哪块区域响应 j/k/h/l），输入法仍可输入。
- `Tab` 顺序：输入框 → 插件图标按钮 → 预览面板/插件内容 → 回到输入框。焦点环 2px 琥珀，偏移 2px。
- 输入法组合输入期间（`compositionstart` 到 `compositionend`）不得触发 Enter 或搜索执行。

## 5. 页面与状态

### 5.1 全局搜索（默认）

展示规则：

- 空查询：按"插件 → 应用"分组，各自按名称升序，最大滚动展示；不展示历史记录。
- 有查询：先按匹配分数排序，同分时插件优先；仍保留两个分组标题。
- 每组最多 4 行即分页滚动，避免分组标题占满窗口。
- 无结果：居中 32px 的 `search-x` 图标 + "没有找到「{query}」" + 提示"试试应用名首字母，或插件关键字，如 fbb、book、剪贴板"。底部提示保留。

```text
┌──────────────────────────────────────────────┐
│  [⌕]  fbb                              [ x ] │
├──────────────────────────────────────────────┤
│  应用                                        │
│  [◈] Foo-Bar-Baz                     ↵       │
│  应用                                        │
│  [◈] Finder                                  │
├──────────────────────────────────────────────┤
│  ↵ 打开    esc 关闭    ctrl J/K 移动          │
└──────────────────────────────────────────────┘
```

模糊匹配规则（与 PRD 对齐）：子序列匹配，连续命中加分，词首命中加分；中文关键字做整串包含匹配。匹配字符逐字高亮。

### 5.2 插件主页面（Shell）

```text
┌──────────────────────────────────────────────┐
│  [⌕]  在剪切板中搜索…                  [◧]  │  插件图标在末尾
├──────────────────────────────────────────────┤
│  剪切板                          设置 ⚙      │  插件自绘内容区
│  ┌────────────────────────────────────────┐  │
│  │ [T]  hello world            文本 · 1m  │  │
│  └────────────────────────────────────────┘  │
├──────────────────────────────────────────────┤
│  ↵ 置顶并关闭   ⌥↵ 粘贴   ctrl ⌫ 删除       │
└──────────────────────────────────────────────┘
```

- 进入插件后输入框清空，`placeholder` 由插件提供；插件声明 `searchable: false` 时，输入框变为只读面包屑（插件图标 + 插件名），不接收键入。
- 输入框末尾固定显示插件图标（28×28 按钮）。点击进入插件设置页；插件无图标时显示 `puzzle` 兜底图标。
- 插件内容区从输入框下沿开始，自身负责滚动、分组与空状态；必须复用本文档的行、面板、焦点令牌。
- 页内标题 20/600，右上角"设置"入口可作为图标按钮的补充（键盘用户可达）。
- `esc`：插件可先消费（如关闭预览/关闭弹层）；未消费则退出插件回到全局搜索，输入框清空并聚焦。

插件与宿主的最小契约：

| 字段 | 说明 |
|---|---|
| `id / name` | 唯一标识、展示名 |
| `keywords` | 支持中英文别名，参与全局模糊匹配 |
| `icon` | 512×512 PNG/SVG；缺省用兜底 |
| `searchable` | 是否复用顶部输入框搜索 |
| `layout` | `compact`（默认）；预留 `wide`，本期不实现 |
| `primaryAction` | 行主操作文案，用于底部提示 |
| `esc` 处理 | 可返回 `consumed`，否则宿主退出插件 |

### 5.3 插件设置页

```text
┌──────────────────────────────────────────────┐
│  [⌕]  Chrome 书签设置…                  [◧]  │
├──────────────────────────────────────────────┤
│  ← 返回     Chrome 书签                       │
│                                              │
│  Chrome Profile                              │
│  [ Default ▾ ]                               │
│  默认使用 Default Profile                    │
│  ~/Library/.../Default  (12px mono)          │
│                                              │
│  已自动保存 ✓                                │
└──────────────────────────────────────────────┘
```

- 设置页由插件自绘，宿主只提供外壳：输入框、插件图标、返回入口、底部快捷键条。
- 表单控件：下拉 32px 高、圆角 8、背景 `surface-2`；数字输入右侧步进器；开关 20×32。
- 标签在上，帮助文字在下（12px 次文字）；不使用 placeholder 当标签。
- 即时保存：修改后 300ms 内应用，右下角出现"已自动保存"内联状态，1.6s 后淡出；不使用"保存"按钮。
- `esc` 先返回插件主页，再按一次退出插件（与"插件可消费 esc"规则一致）。
- 校验失败在字段下方就地展示，12px 危险色 + 图标，不弹全局 Toast。

### 5.4 剪切板插件

默认展示最近记录，列表按时间倒序。每行 56px 以便文本两行。

```text
┌────────────────────────────────────────────────────────────┐
│  [⌕]  在剪切板中搜索…                              [◧]    │
├────────────────────────────────────────┬───────────────────┤
│  [T]  hello world                      │  文本             │
│       第二行文本…            文本 · 1m │  ─────────────    │
│  ┌──────────────────────────────────┐  │  hello world      │
│  │ [▣] 图片缩略图      图片 · 3m    │  │  第二行文本…      │
│  ├──────────────────────────────────┤  │  （完整内容滚动） │
│  │ [▶] 视频封面        视频 · 8m    │  │                   │
│  ├──────────────────────────────────┤  │                   │
│  │ [♪] 音乐            音乐 · 12m   │  │                   │
│  └──────────────────────────────────┘  │  300 × 424        │
├────────────────────────────────────────┴───────────────────┤
│  ↵ 置顶并关闭   ⌥↵ 粘贴   ctrl ⌫ 删除          ? 快捷键     │
└────────────────────────────────────────────────────────────┘
```

列表类型展示：

| 类型 | 列表前置块（36×36） | 列表内容 | 预览面板 |
|---|---|---|---|
| 文本 | `text` 图标，surface-1 底 | 最多 2 行，行高 1.45，末尾省略 | 完整文本，`pre-wrap`，可滚动 |
| 图片 | 缩略图，`object-fit: cover` | 类型 · 时间 | 完整图片，`contain`，深色棋盘底 |
| 视频 | 封面缩略图 + 右下 12px 播放角标 | 封面 + 类型 · 时间 | 封面图（16:9），标注"视频封面"，不播放 |
| 音乐 | `music` 图标 | 文字"音乐" + 类型 · 时间 | 64px 音符图标 + "音乐" + 格式信息 |

预览面板：

- 宽 300px，右侧内缩 8px，圆角 14，背景 `surface-1` + 1px 描边，覆盖在列表右侧；列表在面板打开时为面板让出 308px 右内边距（320ms 过渡，最多 8 行，成本可接受）。
- 停留 1.5s 后展开：选中行底部出现 2px 琥珀进度线（线性 1.5s）；切换选中、鼠标移动超过 8px 或滚动时重置计时并立即收起。
- `ctrl+l` 立即展开预览，`ctrl+h` 收起；预览展开后，`j/k` 仍控制列表选中，预览内容同步更换（不做整块重放动画，仅内容 120ms 交叉淡入）。
- 回车：把该条移动到列表最前，随后播放关闭动画隐藏窗口，系统剪贴板更新为该条，不触发粘贴。
- `option/alt + 回车`：同上，并额外触发一次系统粘贴；界面不额外提示，直接关闭。
- `ctrl+backspace`：删除当前项；行淡出 120ms，后续行用 FLIP 220ms 上移，列表实时更新计数。
- 清空全部：第一次按下快捷键后，底部提示条变为危险色确认条"再按一次，清空全部 12 项"；3s 内再按执行，按 `esc` 或其他键取消。清空后 Toast"已清空剪切板记录"2.4s。
- 空状态：居中 `clipboard` 图标 + "还没有复制记录" + "复制任意文本、图片或文件后，会出现在这里"。

## 6. 键盘交互模型

### 6.1 分层与路由

1. 宿主全局层：`alt/option+space` 开关窗口；剪贴板全局快捷键；`esc` 关闭。
2. 插件层：插件声明并显示的快捷键优先；未消费的 `esc` 回到宿主。
3. 导航层：`ctrl+j/k/h/l` 由宿主统一处理，插件可通过声明接管（如表格类插件），并在底部提示中展示。
4. 输入层：组合输入期间不执行任何命令。

### 6.2 全局快捷键

| 动作 | Linux | macOS | Windows |
|---|---|---|---|
| 开关启动器 | `alt + space` | `option + space` | `alt + space` |
| 打开剪贴板插件 | `ctrl + alt + c` | `control + command + c` | `ctrl + alt + c` |
| 关闭窗口 | `esc` | `esc` | `esc` |

提示文案按平台渲染符号：mac 显示 `⌥ Space`、`⌃ J`；Linux/Windows 显示 `Alt Space`、`Ctrl J`。

### 6.3 光标/选中移动（PRD 核心）

| 键 | 行为 |
|---|---|
| `ctrl + j` | 当前列表选中下一项；到达末尾不循环 |
| `ctrl + k` | 当前列表选中上一项；到达开头不循环 |
| `ctrl + h` | 向左层级：预览收起 / 详情返回 / 无右侧面板时无操作 |
| `ctrl + l` | 向右层级：展开预览或进入选中项详情；无可用目标时无操作 |
| 方向键 | 与 j/k 等价的辅助方式（无障碍要求） |
| 长按 | 系统按键重复生效，步进不受限 |

- 插件页内 `h/l` 优先交给插件处理（横向列表、分栏等），未处理时回落到宿主的"预览/详情"语义。
- 全局搜索页 `h/l` 无副面板，保持无操作，避免误触。
- 选中移动只改变背景与文字，不移动行本身；滚动仅在选中项超出可视区时发生，使用 120ms 缓动。

### 6.4 动作键

| 动作 | 按键 | 说明 |
|---|---|---|
| 打开应用 / 进入插件 / 打开书签 | `enter` | 搜索结果的主操作 |
| 插件内主操作 | `enter` | 行声明的主操作，底部提示同步 |
| 剪贴板置顶并关闭 | `enter` | 更新系统剪贴板，不粘贴 |
| 剪贴板置顶、关闭并粘贴 | `option/alt + enter` | 额外触发一次系统粘贴 |
| 剪贴板删除项 | `ctrl + backspace` | 当前选中项 |
| 剪贴板清空全部 | `super+alt+backspace` / `option+command+backspace` / `win+alt+backspace` | 需二次确认 |
| 插件设置 | 点击输入框末尾图标，或 `tab` 聚焦后 `enter` | |
| 返回 | `esc` | 分层退出 |
| 快捷键帮助 | `?`（shift+/） | 浮层展示当前上下文全部快捷键 |

### 6.5 焦点与选中

- 全局只有一个"选中项"（列表行），鼠标悬停即改变选中；键盘移动同时滚动到可视区。
- 选中项必须始终可见，不被预览面板、footer 或弹层遮挡（WCAG 2.2 焦点不被遮挡）。
- 进入插件时选中重置为第一项；退出插件时回到全局搜索输入态，不保留上次选中。

## 7. 动效系统

### 7.1 基础令牌

| Token | 值 | 用途 |
|---|---|---|
| `--fc-dur-instant` | 120ms | 悬停、选中、内容交叉 |
| `--fc-dur-fast` | 180ms | 关闭、Toast 退场 |
| `--fc-dur-base` | 240ms | 常规过渡、插件退场 |
| `--fc-dur-slow` | 320ms | 面板入场、预览面板 |
| `--fc-dur-slower` | 440ms | 插件内容入场上限 |
| `--fc-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场 |
| `--fc-ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退场 |
| `--fc-spring` | stiffness 320 / damping 30 / mass 0.9 | 需要"流体感"的容器 |
| 退场系数 | 入场时长的 0.55 倍 | 关闭永远比打开快 |

原则：同一时刻最多两个关键元素在动；只使用 `opacity / transform / filter`；`backdrop-filter` 在动画期间保持恒定，不参与补间。

### 7.2 打开 / 关闭

| 阶段 | 属性 | 时长 | 缓动 | 延迟 |
|---|---|---|---|---|
| 遮罩 | opacity 0 → 1 | 180ms | ease-out | 0 |
| 面板 | opacity 0 → 1 | 160ms | ease-out | 0 |
| 面板 | scale 0.96 → 1，y -8 → 0 | 300ms | ease-out（轻微过冲 ≤ 1.5%） | 0 |
| 面板 | filter blur(8px) → 0 | 240ms | ease-out | 0 |
| 结果行 | opacity 0 → 1，y 6 → 0 | 200ms | ease-out | 60ms + i×18ms（最多 8 行） |
| 输入焦点 | 光标出现 | — | — | 120ms |

关闭：总时长 180ms；面板 `opacity → 0`、`scale → 0.98`、`y → -6`，行 80ms 淡出，遮罩 120ms；180ms 后隐藏窗口。关闭动画不得阻塞快捷键再次唤起。

```ts
// Web 技术栈示例（Web Animations API；需要弹簧时改用 Motion/Framer Motion 的 spring 参数）
panel.animate(
  [
    { opacity: 0, transform: 'translateY(-8px) scale(0.96)', filter: 'blur(8px)' },
    { opacity: 1, transform: 'translateY(0) scale(1)', filter: 'blur(0px)' },
  ],
  { duration: 300, easing: 'cubic-bezier(0.16, 1, 0.3, 1)', fill: 'both' },
)
```

### 7.3 进入 / 退出插件

进入（总时长 440ms）：

| 阶段 | 元素 | 变化 | 时长 | 延迟 |
|---|---|---|---|---|
| 1 | 结果列表 | opacity → 0，scale 0.99，y -4，blur 4px | 140ms ease-in | 0 |
| 2 | 插件图标 | scale 0.8 → 1，opacity 0 → 1 | 200ms spring | 80ms |
| 3 | 插件内容 | opacity 0 → 1，y 14 → 0，blur 8 → 0 | 380ms ease-out | 60ms |
| 4 | 输入 placeholder | 120ms 交叉淡入 | 120ms | 80ms |

退出（总时长 240ms）：插件内容 140ms 淡出并下移 8px；结果列表在 80ms 时以 220ms spring 回归（`opacity + y 6 → 0`），不重新 stagger 全量行，仅整体回归。

不使用高度动画。列表与插件内容的交叉通过绝对定位叠层 + opacity/transform 实现，避免容器高度变化导致的重排。

### 7.4 剪贴板预览面板

| 属性 | 值 |
|---|---|
| 入场 | `translateX(28px) → 0`，`opacity 0 → 1`，`scale 0.98 → 1`，`clip-path inset(0 0 0 24px round 14px) → inset(0 round 14px)` |
| 时长/缓动 | 320ms / `--fc-ease-out` |
| 列表让位 | 右内边距 0 → 308px，320ms 同缓动 |
| 停留进度线 | 2px 琥珀，宽度 0 → 100%，1500ms linear |
| 退出 | 180ms，`translateX(16px)` + opacity 0 |
| 内容切换 | 120ms 交叉淡入，不重放入场动画 |
| 触发重置 | 选中变化、滚动、鼠标移动 > 8px、离开窗口 |

```ts
preview.animate(
  [
    { opacity: 0, transform: 'translateX(28px) scale(0.98)', clipPath: 'inset(0 0 0 24px round 14px)' },
    { opacity: 1, transform: 'translateX(0) scale(1)', clipPath: 'inset(0 round 14px)' },
  ],
  { duration: 320, easing: 'cubic-bezier(0.16, 1, 0.3, 1)', fill: 'both' },
)
```

### 7.5 列表增删与筛选

- 删除单条：被删行 120ms 淡出并 `scale 0.98`，随后移除；其余行用 FLIP 220ms 位移上移。
- 搜索筛选：不播放整体移动；新增/移除行 120ms 淡入淡出，禁止每行 stagger 造成"打字卡顿感"。
- 清空：列表整体 160ms 淡出，空状态 180ms 淡入。
- 滚动跟随选中：120ms `scroll-behavior: smooth`；连续按键时改为瞬时滚动，避免追赶动画。

### 7.6 降级与性能

- `prefers-reduced-motion: reduce`：所有动画降为 120ms 纯 opacity；取消 scale、blur、stagger、进度线动画（进度线直接显示或省略）；预览立即出现（保留 1.5s 停留判定，不播放动画）。
- Linux 无合成器模糊：不做 blur 补间，仅 opacity/transform。
- 列表超过 50 行必须虚拟化；1000+ 条书签的匹配放到 Worker，输入防抖 60ms。
- 动画期间对参与元素设置 `will-change: transform, opacity`，`animationend` 后移除。
- 目标：2019 款笔记本集显上稳定 60fps；打开到可输入 ≤ 120ms；上下文切换 ≤ 440ms。

## 8. 无障碍

- 全流程可键盘完成：搜索、移动、进入插件、打开设置、删除、清空、返回都有按键路径。
- 焦点环：2px `--fc-focus-ring`，偏移 2px；任何控件不得 `outline: none` 而无替代。
- 对比度：正文 ≥ 4.5:1，非文字控件/图标 ≥ 3:1；已在上表核算。
- 不以颜色为唯一信息：类型有图标与文字标签，更新状态有文字，选中态有背景 + 字重 + 键帽。
- 屏幕阅读器：结果数量变化通过 `aria-live="polite"` 播报"8 个结果"；进入插件播报"已进入剪切板"；清空播报"已清空 12 项"。
- 预览面板打开时，按钮具备可访问名称；装饰性图标 `aria-hidden`。
- 支持系统"减少动态效果"、"减少透明度"、高对比模式（高对比下边框提升至 0.16 白色、背景不透明）。
- 字体缩放 125% 不截断关键信息；行高与容器使用 `rem`/`em` 比例，避免硬编码高度。
- 停留预览只作为增强：`ctrl+l` 或 Tab + Enter 可立即打开，不依赖悬停计时。

## 12. 待确认问题

1. 技术栈：Electron 还是 Tauri。影响毛玻璃、剪贴板媒体、全局快捷键、窗口置顶的实现成本；本文按 Electron 能力上限设计，Tauri 下 Linux 毛玻璃需降级。
2. 是否首发提供浅色主题；当前只做了令牌兼容。
3. 剪贴板清空是否接受"二次按键确认"（PRD 原文为单次触发）。若坚持单次，需要提供撤销或改为弹层确认。
4. `esc` 在插件内是否允许插件优先消费（如关闭预览）。本文按"允许消费"设计，与 PRD 的"esc 退出插件"一致但更符合层级直觉。
5. 是否允许后续插件声明宽布局（>720px）；本期不实现，避免窗口 resize 动画的三端差异。
6. 是否需要"最近使用"排序；本期空查询只按名称展示，减少未定义行为。
