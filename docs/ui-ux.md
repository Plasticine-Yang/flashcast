# Flashcast UI/UX 设计规范

- 版本：v0.2（蓝色毛玻璃主题）
- 依据：[prd.md](./prd.md)
- 设计基线：蓝色玻璃拟态（Blue Glass）+ 极简单列启动器；Inter 字体；键盘优先；高动效强度
- 本文档是 UI 的 Source of Truth：颜色、尺寸、动效、键盘行为均以这里为准
- 变更：v0.2 用「Blue Glass」替换深色琥珀方案，补齐浅色主题、玻璃层级、选中行与设置窗口极光背景；启动器加入壁纸磨砂层

---

## 1. 设计目标

| 原则 | 含义 | 落到界面上 |
|---|---|---|
| 瞬时 | 按下快捷键到可用不超过 120ms | 窗口先出现再动画，入场动画不阻塞输入 |
| 单一焦点 | 任何时候只有一个输入框 | 全局搜索、插件搜索都复用同一个输入框 |
| 键盘优先 | 所有操作可无鼠标完成 | 选中态、焦点环、底部快捷键提示必须可见 |
| 流体但克制 | 动画表达层级变化，不做无意义装饰 | 默认只动 opacity / transform / filter；面板外壳生长是唯一例外（固定内层布局的高度过渡） |
| 平台原生 | 三端看起来都像"属于这个系统" | 毛玻璃、圆角、阴影、快捷键符号按平台适配 |

视觉基调：雾蓝玻璃面板 + 单一蔚蓝强调色。深色是深蓝海面、浅色是清晨薄雾，两套主题各自设计而不是简单反色。面板会吸收当前桌面壁纸的模糊色相，像一块真正压在桌面上的磨砂玻璃；再用 1px 发光描边、内部光源、磨砂颗粒与留白表达层次，不堆叠装饰性插画、彩色渐变或 3D 效果。

---

## 2. 设计假设（待确认）

1. 技术栈未定。本文以 Web 技术栈（Electron / Tauri WebView）描述实现，毛玻璃与全局快捷键需要原生能力配合。
2. 窗口固定尺寸 `720 × 480`，出现在当前显示器上方约 18% 处；不随内容自动变宽。
3. 深色与浅色都是正式主题，两套令牌分别核算对比度；跟随系统时随系统外观切换。
4. 剪贴板预览使用右侧浮层，不改变窗口宽度，避免三端窗口 resize 卡顿。
5. `esc` 分层退出：从全局搜索页进入插件时退出插件；通过剪切板全局快捷键直接进入剪切板时直接关闭窗口；预览面板本身不再消费 `esc`。设置页先返回插件主页。

### 3.1.1 玻璃层级（两套主题共用的结构）

| Token | 深色 | 浅色 | 作用 |
|---|---|---|---|
| `--fc-glass-sheen` | 左上蓝色光源 + 右下青色折射 | 左上白色高光 + 右下淡蓝折射 | 面板内部光源，让玻璃"有厚度" |
| `--fc-glass-border` | `rgba(150,193,255,0.22)` | `rgba(255,255,255,0.9)` | 外描边 |
| `--fc-glass-rim-top` / `-bottom` | 冷白 / 淡蓝 | 纯白 / 淡蓝 | 内侧 1px 边缘高光 |
| `--fc-glass-filter` | `blur(44px) saturate(1.6) brightness(.72)` | `blur(44px) saturate(1.5) brightness(1.06)` | 页面内叠加层的毛玻璃（预览、弹窗） |
| `--fc-glass-filter-soft` | `blur(20px) saturate(1.5) brightness(.85)` | `blur(20px) saturate(1.35) brightness(1.04)` | 卡片、侧栏、Toast |
| `--fc-scrim` | `rgba(4,10,22,0.58)` | `rgba(226,238,255,0.6)` | 帮助 / 弹窗背后的冷色遮罩 |
| `--fc-frost` / `--fc-frost-opacity` | 180px 单色噪点 / `0.045` | 同左 / `0.035` | 磨砂颗粒，让玻璃有物理质感 |
| `--fc-wallpaper-opacity` | `0.5` | `0.42` | 壁纸磨砂层的强度 |
| `--fc-wallpaper-blur` | `64px` | 同左 | 壁纸模糊半径 |
| `--fc-aurora` | 深蓝极光 | 清晨蓝调极光 | 设置窗口的天空背景 |

`backdrop-filter` 只采样页面内部内容，Electron 透明窗口外的桌面不在采样范围内。启动器因此用三层完成毛玻璃：

1. 半透明蓝底 + 内部光源（`--fc-window` + `--fc-glass-sheen`）；
2. 当前桌面壁纸的重度模糊层（`--fc-wallpaper-*`），以 `mix-blend-mode: color` 混入，只取色相与饱和度、保留面板自身亮度——所以壁纸再亮也不会降低文字对比度；
3. 磨砂颗粒（`--fc-frost`）与内描边。

壁纸来自 GNOME（`gsettings` 的 `picture-uri` / `picture-uri-dark`）或 Windows（注册表 `HKCU\\Control Panel\\Desktop`），由 `flashcast-wallpaper://` 协议下发给渲染进程；读不到壁纸（例如 macOS 没有免授权接口）时自动退回第 1 + 3 层。设置窗口中卡片叠加在极光背景上，`backdrop-filter` 是真实可见的。

### 3.1.2 对比度

按 sRGB 相对亮度核算，取最差合成背景：

- 深色面板：`rgba(11,19,37,0.8)` 叠在纯白桌面上，含 sheen 后约 `#3D485F`。主文字 ≈ 8.5:1、次文字 ≈ 5.8:1、三级文字 ≈ 5.0:1、强调色 ≈ 5.1:1；选中行改用深蓝底后仍 ≥ 5.3:1。
- 浅色面板：`rgba(240,247,255,0.82)` 叠在近黑桌面上，约 `#C6CCD4`。主文字 ≈ 10.6:1、次文字 ≈ 6.2:1、三级文字 ≈ 4.7:1、强调色 ≈ 4.6:1；选中行使用近白蓝后 ≥ 6.3:1。
- 设置窗口玻璃卡片叠在极光最亮处：次文字 ≥ 6.8:1、三级文字 ≥ 5.8:1。

深色 0.92、浅色 0.90 是当前面板的不透明度；壁纸磨砂层只改变色相，不改变合成亮度。高对比模式与“减少透明度”会隐藏壁纸层并强制接近不透明。

### 3.4 间距、圆角、层级

- 间距基数 4px，常用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。窗口内部左右边距 12，行内边距 12，垂直节奏 8。
- 圆角：窗口 20，行 10，预览面板 14，按钮 8，键帽 6，图标容器 9，应用图标 8。
- 阴影：深色 `0 32px 90px rgba(0,6,20,0.62)` + `0 6px 24px rgba(0,6,20,0.36)`；浅色 `0 30px 84px rgba(21,48,96,0.18)`；两者都带 1px 内侧高光 `--fc-glass-rim-top`。按钮使用 `--fc-shadow-accent` 的蓝色投影，不再用纯黑。
- 图标：Lucide，线性 1.5px；尺寸 `16 / 20 / 24 / 28 / 32`；应用图标 32，插件图标 28，输入框插件按钮 28。
- 禁止 emoji 当图标；插件未提供图标时用 `puzzle` 线性图标兜底。

## 4. 窗口与布局

### 4.1 窗口规格

| 项 | 规格 |
|---|---|
| 尺寸 | `720 × 480`，最小 `640 × 400` |
| 位置 | 当前显示器水平居中，距工作区顶部 18%（最高不超过 160px） |
| 层级 | 置顶、跨工作区显示、任务栏/Dock 隐藏、无标题栏 |
| 圆角 | 18px，Windows 11 取系统圆角上限 |
| 背景 | 半透明蓝色毛玻璃 + 1px 冷色描边 + 内部光源 |
| 全屏背景 | 不做压暗遮罩；面板外桌面保持原样。透明全屏层只用于点击外部关闭，不参与视觉 |
| 多屏 | 使用鼠标所在屏；记住上次位置并校验是否在工作区内 |

平台兜底：

- 三端统一使用透明窗口 + CSS 半透明蓝玻璃；桌面级实时模糊（macOS `NSVisualEffectView` / Windows Mica）本期不启用，避免整屏模糊。
- 壁纸磨砂：GNOME 读取 `org.gnome.desktop.background`，Windows 读取注册表；macOS 无免授权壁纸接口，回退纯玻璃。
- Linux：GNOME/KWin 等合成器下透明窗口正常工作；面板依靠内部光源与描边保持玻璃质感，不承诺桌面级模糊。
- 不支持 `backdrop-filter` 时退回 `--fc-window-solid`；系统开启"减少透明度"时 `--fc-glass-filter` 变为 `none`，窗口接近不透明。
- 设置窗口使用不透明原生窗口，内部绘制 `--fc-aurora` 天空背景，侧栏与卡片在其上做真实模糊。

```text
│  [⌕]  搜索应用、插件或命令      [↑ 更新 v0.3.0] [◧] [⚙] │  60px
├──────────────────────────────────────────────────────────┤  1px
│  插件                                                    │  24px
│  ┌────────────────────────────────────────────────────┐  │
│  │ [◧] 剪切板    最近复制的内容…                  [↵] │  │  48px
│  └────────────────────────────────────────────────────┘  │
│  应用                                                    │  24px
│  ┌────────────────────────────────────────────────────┐  │
│  │ [◈] Chrome                            浏览器       │  │  48px
│  └────────────────────────────────────────────────────┘  │
│  ...                                                     │
├──────────────────────────────────────────────────────────┤  38px
│  ↵ 打开     esc 关闭     ctrl J/K 移动            ? 快捷键 │

```

- 输入区 60px：搜索图标 20、间距 12、输入文字 18；右侧为动作区，从左到右是更新按钮（仅在有可操作更新时出现）、清空、插件图标（仅进入插件后出现）、设置齿轮（始终出现，`⌘,` / `Ctrl+,` 等价）。
- 列表区可滚动，一屏约 7 行；滚动条为 6px overlay，仅在滚动时出现。
- 底部 38px 为上下文快捷键条，按键帽 + 文案组合，最高 4 条；右侧固定 `?` 打开快捷键帮助浮层。

| 元素 | 规格 |
|---|---|
| 行高 | 48px，行间距 2px，圆角 10px，内边距 `0 12px` |
| 前置图标 | 32×32，圆角 8；应用用系统图标，插件用插件图标，书签用 favicon |
| 主标题 | 15/500，单行，`text-overflow: ellipsis` |
| 副标题 | 12/400 次文字，单行；应用=类别/路径，书签=URL，插件=关键字说明 |
| 尾部 | 选中时显示 `↵` 键帽；书签显示文件夹 chip；剪贴板显示"类型 · 相对时间" |

### 4.4 焦点区域

```text
[ 搜索输入 ] ──ctrl+l──▶ [ 插件设置字段 ]
      ▲                         │
      └──────── ctrl+h ─────────┘
```

- 输入框默认始终持有键入焦点；插件设置页内 `ctrl+h/l` 在输入框与可聚焦字段之间切换。剪切板预览不接受焦点，也不响应 `h/l`。
- `Tab` 顺序：输入框 → 更新按钮 → 清空 → 插件图标 → 设置齿轮 → 插件内容/设置字段 → 回到输入框。焦点环 2px 蔚蓝，偏移 2px。
- 更新按钮只在 `available / downloading / ready / installing` 存在，其余状态下完全不渲染（不为它预留空位，避免"空槽"）；它出现时从 opacity/scale 220ms 弹入，输入框宽度随之收缩，右侧三个动作按钮位置不变。
- 输入法组合输入期间（`compositionstart` 到 `compositionend`）不得触发 Enter 或搜索执行。

## 5. 页面与状态

### 5.1 全局搜索（默认）

展示规则：

- 空查询：按"插件 → 应用"分组，各自按名称升序，最大滚动展示；不展示历史记录。
- 有查询：先按匹配分数排序，同分时插件优先；仍保留两个分组标题。
- 每组最多 4 行即分页滚动，避免分组标题占满窗口。
- 无结果：居中 32px 的 `search-x` 图标 + "没有找到「{query}」" + 提示"试试应用名首字母，或插件关键字，如 fbb、book、剪贴板"。底部提示保留。

```text
┌──────────────────────────────────────────────┐
│  [⌕]  fbb                              [ x ] │
├──────────────────────────────────────────────┤
│  应用                                        │
│  [◈] Foo-Bar-Baz                     ↵       │
│  应用                                        │
│  [◈] Finder                                  │
├──────────────────────────────────────────────┤
│  ↵ 打开    esc 关闭    ctrl J/K 移动          │
└──────────────────────────────────────────────┘
```

模糊匹配规则（与 PRD 对齐）：子序列匹配，连续命中加分，词首命中加分；中文关键字做整串包含匹配。匹配字符逐字高亮。

### 5.2 插件主页面（Shell）


- 进入插件后输入框清空，`placeholder` 由插件提供；插件声明 `searchable: false` 时，输入框变为只读面包屑（插件图标 + 插件名），不接收键入。

| 字段 | 说明 |
|---|---|

## 6. 键盘交互模型

### 6.1 分层与路由

1. 宿主全局层：`alt/option+space` 开关窗口；剪贴板全局快捷键；`esc` 关闭。
2. 插件层：插件声明并显示的快捷键优先；未消费的 `esc` 回到宿主。
3. 导航层：`ctrl+j/k/h/l` 由宿主统一处理，插件可通过声明接管（如表格类插件），并在底部提示中展示。
4. 输入层：组合输入期间不执行任何命令。

### 6.2 全局快捷键

| 动作 | Linux | macOS | Windows |
|---|---|---|---|
| 开关启动器 | `alt + space` | `option + space` | `alt + space` |
| 打开剪贴板插件 | `ctrl + alt + c` | `control + command + c` | `ctrl + alt + c` |
| 关闭窗口 | `esc` | `esc` | `esc` |

提示文案按平台渲染符号：mac 显示 `⌥ Space`、`⌃ J`；Linux/Windows 显示 `Alt Space`、`Ctrl J`。

### 6.3 光标/选中移动（PRD 核心）

| 键 | 行为 |
|---|---|
| `ctrl + j` | 当前列表选中下一项；到达末尾不循环 |
| `ctrl + k` | 当前列表选中上一项；到达开头不循环 |
| `ctrl + h` / `ctrl + l` | 插件设置页内左右切换可聚焦字段；其他页面无操作 |
| 方向键 | 与 j/k 等价的辅助方式（无障碍要求） |
| 长按 | 系统按键重复生效，步进不受限 |

- 剪切板页面不再用 `h/l` 收起或展开预览；预览始终常驻，只有离开插件或没有选中项时消失。
- 插件设置页 `h/l` 在字段间移动；其他插件页的 `h/l` 留给插件自行处理。
- 选中移动只改变背景与文字，不移动行本身；键盘移动时若选中项超出可视区，才以 120ms 缓动滚入视野。鼠标悬停不滚动列表。

### 6.4 动作键

| 动作 | 按键 | 说明 |
|---|---|---|
| 打开应用 / 进入插件 / 打开书签 | `enter` | 搜索结果的主操作 |
| 插件内主操作 | `enter` | 行声明的主操作，底部提示同步 |
| 剪贴板置顶并关闭 | `enter` | 更新系统剪贴板，不粘贴 |
| 剪贴板置顶、关闭并粘贴 | `option/alt + enter` | 额外触发一次系统粘贴 |
| 剪贴板删除项 | `ctrl + backspace` | 当前选中项 |
| 剪贴板清空全部 | `super+alt+backspace` / `option+command+backspace` / `win+alt+backspace` | 需二次确认 |
| 插件设置 | 点击输入框末尾图标，或 `tab` 聚焦后 `enter` | |
| 打开应用设置 | `⌘,`（macOS）/ `ctrl+,`（Linux、Windows），或点击顶栏齿轮 | 与插件设置区分 |
| 返回 | `esc` | 分层退出 |
| 快捷键帮助 | `?`（shift+/） | 浮层展示当前上下文全部快捷键 |

### 6.5 焦点与选中

- 全局只有一个"选中项"（列表行），鼠标悬停即改变选中；键盘移动同时滚动到可视区。
- 选中项必须始终可见，不被预览面板、footer 或弹层遮挡（WCAG 2.2 焦点不被遮挡）。
- 进入插件时选中重置为第一项；退出插件时回到全局搜索输入态，不保留上次选中。

## 7. 动效系统

### 7.1 基础令牌

| Token | 值 | 用途 |
|---|---|---|
| `--fc-dur-instant` | 120ms | 悬停、选中、列表内容更新 |
| `--fc-dur-fast` | 180ms | 关闭、Toast 退场 |
| `--fc-dur-base` | 240ms | 常规过渡、插件退场 |
| `--fc-dur-slow` | 320ms | 列表让位、常规慢过渡 |
| `--fc-dur-slower` | 440ms | 插件内容入场上限 |
| `--fc-ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场 |
| `--fc-ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退场 |
| `--fc-spring` | stiffness 320 / damping 30 / mass 0.9 | 需要"流体感"的容器 |
| 退场系数 | 入场时长的 0.55 倍 | 关闭永远比打开快 |

面板外壳（470ms 打开 / 170ms 关闭）与预览水珠（420ms 展开）使用专用时长，不复用 `--fc-dur-slow`。

原则：同一时刻最多两个关键元素在动；默认只使用 `opacity / transform / filter`；唯一例外是 7.2 的面板外壳高度生长（内层固定高度，只做裁剪）；`backdrop-filter` 在动画期间保持恒定，不参与补间。

### 7.2 打开 / 关闭

打开是两段式“输入框先出现，列表再从输入框底部流出来”，不是整块面板做 scale / blur / translate 弹出。实现上 `.fc-panel` 初始只有 62px 高（60px 输入区 + 上下描边），`.fc-panel-inner` 始终按最终高度排版；外壳变高时只裁剪，内层不发生重排。全程不做全屏压暗遮罩。

| 阶段 | 元素 | 变化 | 时长 / 缓动 |
|---|---|---|---|
| 0–85ms | 面板外壳 | 高度固定 62px，只做 opacity 0 → 1；输入框始终停在最终位置 | 85ms ease-out |
| 85–348ms | 面板外壳 | 高度 62px → 最终高度（480px），列表与 footer 随下边缘逐行露出；348ms 时过冲 +5px | `cubic-bezier(0.32, 0, 0.22, 1)` |
| 348–470ms | 面板外壳 | 从 +5px 过冲回落到最终高度 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 110ms 起 | 结果行 | opacity 0 → 1，y 6 → 0，第 i 行延迟 110ms + i×20ms（最多 8 行） | 240ms ease-out |
| 关闭 0–122ms | 面板外壳 | 当前高度 → 62px，像液体被吸回输入框 | 170ms ease-in |
| 关闭 122–170ms | 面板外壳 | opacity → 0；180ms 后隐藏窗口 | 170ms ease-in |

- 全屏背景保持桌面原样；点击面板外的透明层只负责关闭，不改变亮度。
- 整个外壳不播放 scale / translateY / blur；输入框不随面板移动。
- 焦点与键入在动画开始前就绪，动画不阻塞输入；输入区约 85ms 可见，满足“打开到可输入 ≤120ms”。
- 结果行延迟到 110ms 才开始出现，保证第一阶段确实只有输入框，不会提前看到列表。
- 关闭先收缩再淡出，关闭动画不得阻塞快捷键再次唤起。

```ts
// 外壳：两段式高度生长（内层固定高度，只裁剪）
panel.animate(
  [
    { opacity: 0, height: '62px', offset: 0 },
    { opacity: 1, height: '62px', offset: 0.18, easing: 'cubic-bezier(0.32, 0, 0.22, 1)' },
    { opacity: 1, height: '485px', offset: 0.74, easing: 'cubic-bezier(0.4, 0, 0.2, 1)' },
    { opacity: 1, height: '479px', offset: 0.9, easing: 'ease-out' },
    { opacity: 1, height: '480px', offset: 1 },
  ],
  { duration: 470, easing: 'linear', fill: 'both' },
)
```

### 7.3 进入 / 退出插件

进入（总时长 440ms）：

| 阶段 | 元素 | 变化 | 时长 | 延迟 |
|---|---|---|---|---|
| 1 | 结果列表 | opacity → 0，scale 0.99，y -4，blur 4px | 140ms ease-in | 0 |
| 2 | 插件图标 | scale 0.8 → 1，opacity 0 → 1 | 200ms spring | 80ms |
| 3 | 插件内容 | opacity 0 → 1，y 14 → 0，blur 8 → 0 | 380ms ease-out | 60ms |
| 4 | 输入 placeholder | 120ms 交叉淡入 | 120ms | 80ms |

退出（总时长 240ms）：插件内容 140ms 淡出并下移 8px；结果列表在 80ms 时以 220ms spring 回归（`opacity + y 6 → 0`），不重新 stagger 全量行，仅整体回归。

插件内容与列表的交叉不使用高度动画；两者通过绝对定位叠层 + opacity/transform 实现，避免容器高度变化导致的重排。启动器外壳的高度生长是唯一例外，见 7.2。

### 7.4 剪贴板预览面板

预览是剪切板页面的默认组成部分；进入界面就展开，不做悬停停留延迟。出场仍必须从选中行“流出来”：先是一枚贴着预览左缘的小水珠，再向上下左右展开成 300px 面板。

| 阶段 | 属性 | 时长 / 缓动 |
|---|---|---|
| 默认状态 | 进入剪切板且存在选中项时立即展开；无停留、无进度线 | — |
| 水珠 | 在选中行中心对应的预览左缘生成约 12×8px、圆角 6px 的水珠；`opacity 0 → 1`，`translateX 22 → 16px` | 0–67ms linear |
| 展开 | `clip-path` 从水珠的 `inset(top 右侧剩余 bottom 0 round 6px)` 展开到 `inset(0 round 14px)`；`translateX 16 → 0` | 67–420ms `cubic-bezier(0.16, 1, 0.3, 1)` |
| 列表让位 | 右内边距 0 → 320px | 320ms `--fc-ease-out` |
| 内容切换 | 原位替换，不重放水珠展开，也不做整层淡入（避免快速 `j/k` 时内容闪空） | 即时 |

- 水珠的纵向位置在打开瞬间从选中行与预览的实际 rect 计算；选中行靠近顶部/底部时水珠向内收，不超出面板。
- 已展开时：鼠标移动和 `j/k` 切换只更新内容与选中，不收起、不重放入场；不再存在“等待 1s 才出现”的中间阶段。
- 预览是剪切板页面的常驻部分，没有关闭按钮，也不再响应 `esc` / `ctrl+h` / `ctrl+l`；只有离开插件或搜索无结果时消失。
- 预览展开不改变窗口宽度；列表通过右内边距让位，预览本身是绝对定位浮层。

```ts
// 打开：从选中行中心的水珠展开（clip-path + translate 同时进行）
preview.animate(
  [
    { opacity: 0, transform: 'translateX(22px)', clipPath: beadPath, offset: 0 },
    { opacity: 1, transform: 'translateX(16px)', clipPath: beadPath, offset: 0.16 },
    { opacity: 1, transform: 'translateX(0)', clipPath: 'inset(0 round 14px)', offset: 1 },
  ],
  { duration: 420, easing: 'linear', fill: 'both' },
)
```

### 7.5 列表增删与筛选

- 删除单条：被删行 120ms 淡出并 `scale 0.98`，随后移除；其余行用 FLIP 220ms 位移上移。
- 搜索筛选：不播放整体移动；新增/移除行 120ms 淡入淡出，禁止每行 stagger 造成"打字卡顿感"。
- 清空：列表整体 160ms 淡出，空状态 180ms 淡入。
- 滚动跟随选中：120ms `scroll-behavior: smooth`；连续按键时改为瞬时滚动，避免追赶动画。

### 7.6 降级与性能

- `prefers-reduced-motion: reduce`：所有动画降为 120ms 纯 opacity；取消 scale、blur、stagger、外壳高度生长与水珠展开；预览在最终位置以 120ms 淡入（常驻、无停留延迟），离开插件时随视图一起淡出。
- 面板高度生长期间只改变外壳高度与裁剪，内层固定为最终内容高度（480px 外壳 / 478px 内容区），不触发列表重排。
- Linux 无合成器模糊：不做 blur 补间，仅 opacity/transform。
- 列表超过 50 行必须虚拟化；1000+ 条书签的匹配放到 Worker，输入防抖 60ms。
- `will-change` 只设置在外壳、预览这类参与动画的容器上，不给每一行常驻提升合成层。
- 目标：2019 款笔记本集显上稳定 60fps；打开到可输入 ≤ 120ms；上下文切换 ≤ 440ms。

## 8. 无障碍

- 全流程可键盘完成：搜索、移动、进入插件、打开设置、删除、清空、返回都有按键路径。
- 焦点环：2px `--fc-focus-ring`，偏移 2px；任何控件不得 `outline: none` 而无替代。
- 对比度：正文 ≥ 4.5:1，非文字控件/图标 ≥ 3:1；已在上表核算。
- 不以颜色为唯一信息：类型有图标与文字标签，更新状态有文字，选中态有背景 + 字重 + 键帽。
- 屏幕阅读器：结果数量变化通过 `aria-live="polite"` 播报"8 个结果"；进入插件播报"已进入剪切板"；清空播报"已清空 12 项"；更新按钮在可更新/就绪/安装时用 `aria-live` 播报一次，下载进度用 `progressbar` 的 `aria-valuenow`，不逐百分比打断。
- 预览面板是只读内容区，不抢焦点；剩余装饰性图标 `aria-hidden`。
- 支持系统"减少动态效果"、"减少透明度"、高对比模式（高对比下描边提升至冷白、面板接近不透明，见 `data-contrast="more"` 令牌）。
- 字体缩放 125% 不截断关键信息；行高与容器使用 `rem`/`em` 比例，避免硬编码高度。
- 预览常驻展开，不依赖悬停计时，也不提供收起快捷键。

## 12. 待确认问题

1. 技术栈：Electron 还是 Tauri。影响毛玻璃、剪贴板媒体、全局快捷键、窗口置顶的实现成本；本文按 Electron 能力上限设计，Tauri 下 Linux 毛玻璃需降级。
2. 是否首发提供浅色主题；当前只做了令牌兼容。
3. 剪贴板清空是否接受"二次按键确认"（PRD 原文为单次触发）。若坚持单次，需要提供撤销或改为弹层确认。
4. `esc` 在插件内是否允许插件优先消费（如关闭弹层）。本文按"允许消费弹层"设计；剪切板预览不再消费 `esc`，并且从全局快捷键直接进入剪切板时 `esc` 直接关闭窗口，与 PRD 的"esc 退出插件"在普通插件路径上保持一致。
5. 是否允许后续插件声明宽布局（>720px）；本期不实现，避免窗口 resize 动画的三端差异。
6. 是否需要"最近使用"排序；本期空查询只按名称展示，减少未定义行为。
