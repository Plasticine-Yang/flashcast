# ADR 0002：插件契约与主题、模式、风格分离

Status: accepted

主题身份、用户的深浅偏好和主题提供的表面风格独立。用户选择电弧后可在同一主题内切换毛玻璃、液态外观或实底；其他主题可以只提供一种非玻璃风格。所有新主题必须交付深浅两套，功能插件使用宿主语义组件适配两种外观。减少透明度和平台降级优先使用主题的实底回退。

本决策扩展 ADR 0001 §7：旧版浅色、深色、跟随系统主题只保留兼容读取；新安装走 v2 契约。共同插件契约明确 API、宿主兼容范围与配置版本，未知效果必须由宿主新增声明式渲染器，不能执行主题代码。功能插件仍编译注册；本版不开放任意第三方代码运行。

工作区保存可迁移偏好，系统外观和平台效果支持状态留在设备。配置先校验并原子写入，再生效；无效配置保留完整的上一次可用外观。风格按主题保存，避免把电弧材质强加给未来主题。
