# ADR 0003：显式插件页面与统一页面命令

状态：已接受（2026-10-06）

用户选定 03「动作托盘」。本决策替换 ADR 0001 §4 中「完整关键词自动进入／清空输入返回首屏／标签命中直接粘贴」的交互：输入始终只过滤当前查询范围。主搜索没有插件 Tab，软件、插件入口和备忘录标签结果共享列表。

## 页面与查询

选择插件入口并回车，执行稳定页面命令，进入空查询的插件页面；清空插件内查询显示全部内容。Esc 恢复进入前的查询与选中项。备忘录标签结果优先排序；第一次回车进入备忘录页面，携带查询和选中结果，第二次回车粘贴正文。显式进入不依赖输入文本，bookmark 等别名不会被当成插件内查询前缀。

插件页面承担功能：备忘录 CRUD 使用保留失败草稿的弹窗；剪切板左历史右完整文本／图片预览，置顶、删除和清空集中到动作托盘；书签继续过滤后交给关联 Chrome profile 打开。设置只承载启停、来源关联、保留范围和快捷键，不承载历史浏览或文件副本操作。旧的本机副本数据仍可读取，界面不再提供新增副本动作。

## 命令贡献

`FeaturePlugin::commands()` 返回 `PluginCommand`。默认贡献 `flashcast.plugin.<plugin-id>` 页面入口；命令含稳定 ID、页面目标、名称和三个平台的默认快捷键。自定义 ID 限定在自身命名空间（例如 `flashcast.plugin.example.notes.open`），多个命令可以指向同一插件页面。注册时校验命名空间、重复 ID 和按键语法，保持已有插件源码兼容。

`Settings.commandShortcuts` 保存平台各自的用户覆盖。缺失／null 使用默认值，空字符串禁用绑定。当前平台有效命令与主唤起快捷键冲突时拒绝保存或启用，保留此前配置。剪切板默认 Linux／Windows `Ctrl+Alt+C`、macOS `Control+Command+C`，默认停用的插件不注册。

核心宿主解析配置与页面目标；Tauri 外壳负责注册、授权、窗口和运行状态。门户授权在工作线程，普通注册在主线程（Windows 绑定注册线程）。命令快捷键传入自己的门户 ID 和名称；迟到授权不能覆盖新设置，停用即阻止回调并注销。配置值、实际生效按键、待授权和错误分别展示。注册失败时旧绑定仍可用，错误显示在配置页。

## 扩展边界

功能插件仍随应用编译注册，此次不引入下载任意代码或独立进程 SDK。独立仓库可以作为受信任 Rust crate 被宿主引用；在当前仓库新增插件同样实现贡献接口，并通过宿主入口验证搜索、执行、禁用和失败路径。未来独立载体需要另行定义隔离、安装、更新与权限，而不是在 UI 里绕过命令注册机制。
