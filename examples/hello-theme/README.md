# Hello Harbor

一个最小的工作区主题包示例：深海蓝底 + 海港青强调色，深色与浅色成对。它只包含数据，不包含任何 JavaScript。

## 安装

1. 打开 **设置 → 外观**。
2. 点击右上角 **安装主题**。
3. 在输入框中填写本目录的**绝对路径**，例如在仓库根目录执行 `pwd` 后拼上 `/examples/hello-theme`。
4. 点击 **检查主题**，确认主题 ID、版本、作者与许可后点击 **确认安装**。
5. 安装完成后回到主题画廊选择 **Hello Harbor**。主题文件会写入工作区的 `themes/hello-harbor/`，并纳入工作区 Git（自动提交开启时立即提交；关闭时需手动提交并推送，另一台电脑才能恢复）。

也可以把本目录推送到一个 Git 仓库，在安装弹窗中填写仓库 URL。安装器只读取仓库中的 `theme.json` 与可选的 `LICENSE`。

## 文件

| 文件 | 作用 |
|---|---|
| `theme.json` | schema v1 主题定义：元数据、深/浅两套 palette、少量令牌覆盖 |
| `LICENSE` | MIT 许可；安装时随主题一起复制 |

## 配色

| 角色 | 深色 | 浅色 | 说明 |
|---|---|---|---|
| `bg` | `#071a1e` | `#f3faf8` | 深海夜色 / 清晨薄雾 |
| `accent` | `#5fd7cf` | `#0f6b66` | 海港青航标；浅色改用深青保证文字对比 |
| `accentFill` | `#0f766e` | `#0f766e` | 主按钮填充，白字对比 5.47:1 |
| `text` | `#e8f7f5` | `#0f2a2c` | 近白薄荷 / 墨青 |
| `danger` | `#ff9b8a` | `#9e2b24` | 仅用于删除、错误等功能语义，不做装饰 |

两套 palette 均通过 [docs/themes.md](../../docs/themes.md) 描述的硬性对比度校验：正文、次级、三级文字、强调色、成功、警告、危险色对 `bg` ≥ 4.5:1，焦点环 ≥ 3:1，`onAccent` 对 `accentFill` ≥ 4.5:1。实际比值见 `docs/themes.md` 的示例。
